# AI-журнал

Каждый цикл роя оставляет здесь запись: что за задача, какие агенты работали,
сколько раундов dev↔ревью, что вернул security и чем всё закончилось. Записи
пишет оркестратор детерминированно (без LLM) — факты, не художество.

- Шаблон: `_TEMPLATE.md`
- Логи циклов (сырые): `.task-board/log/` (не коммитятся)
- Диаграмма процесса: `docs/ai-process.md`
