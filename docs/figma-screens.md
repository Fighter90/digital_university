## Как executor'у сверяться с макетом

1. Открой задачу в Linear — в описании ссылка на фрейм.
2. Если задан `FIGMA_TOKEN` — вытяни данные ноды через REST API
   (`https://api.figma.com/v1/files/dP2lFEahhw1gBbMRKX7BD2/nodes?ids=...`).
3. Без токена — работай по описанию фрейма в задаче и токенам из DIG-13.
4. Сверка результата — скриншотами Playwright: 1440×900 и 360×800.
