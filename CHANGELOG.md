# Changelog


### Unreleased

#### Изменения
- **Добавлена изоляция данных (DIG-12)**: страницы и API читают данные
  только через слой `src/server/data/*`, где фильтр по владельцу вшит в
  контекст сессии; чужая заявка и несуществующая отвечают одинаковым 404,
  попытки чужого доступа пишутся в журнал аудита, сотрудник видит студентов
  только своего факультета, заявки в URL адресуются не-последовательными
  номерами (`SR-2026-A1B2C`). Прямой импорт Prisma вне `src/server/`
  запрещён правилом ESLint (тесты закрепляют). Появились экраны «Мои заявки»
  и детальная заявка с историей, API заявки, единая страница 404 и
  вымышленные демо-аккаунты жюри (Анна, Илья, Мария).
- **Добавлен вход по логину и паролю** (DIG-11): серверные сессии на
  httpOnly-куках, хэширование паролей, защита от перебора по IP, route-guard
  через middleware и форма логина; покрыто unit-тестами и e2e-сценарием
  входа.

#### Заметки
- Специально не делали: восстановление пароля по email и 2FA — это отдельная
  задача, в этот раз ограничились базовым входом и сессиями.
- Специально не делали (DIG-12): ICS-фид, PDF-справка и чат AI — поверхностей
  ещё нет; их задачи обязаны идти через слой `src/server/data/*` и единый
  404-хелпер (проверяется security-агентом в каждом PR).
Все значимые изменения проекта документируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
