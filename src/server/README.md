# src/server

Серверный слой: доступ к данным, сервисы, авторизация, server actions.

- `actions/` — server actions (мутации), каждая проверяет сессию и владельца данных (IDOR-запрет, AGENTS.md).
- Подключение Prisma/PostgreSQL и сессий — в отдельных задачах (DIG-18+).

Код отсюда не должен импортироваться из клиентских компонентов.
