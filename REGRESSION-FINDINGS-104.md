## Дефекты

### F-1 · HIGH · Гидрация расписания падает с React #418 (вложенные `<a>`)

- **Что:** на `/schedule` (авто) и `/schedule?view=day` — desktop и mobile —
  необработанная ошибка `Minified React error #418` («Hydration failed…»).
  React выбрасывает её после гидрации и перерисовывает всё дерево на клиенте:
  SSR-разметка отбрасывается, лишняя работа на каждый визит, ошибка в консоли
  (критерий «консоль без ошибок» не выполняется).
- **Где:** `src/components/schedule/event-card.tsx` — карточка пары целиком
  `<a>` (DIG-24), внутри неё ссылка преподавателя `<Link>` (DIG-37) —
  вложенный якорь. Невалидный HTML: парсер браузера переставляет дерево
  (`<a>` внутри `<a>`), серверная разметка не совпадает с клиентской.
  Затронуты вид «день» (десктопный список `DayView` и мобильная лента
  `MobileSchedule`); «неделя»/«месяц» чисты — там ссылки преподавателя нет.
- **Серьёзность:** HIGH — падение гидрации на главном экране студента
  при каждом открытии; функционал при этом восстанавливается перерисовкой,
  но ошибка в консоли и лишний рендер всего дерева на клиенте.
- **Воспроизведение:** прод (`ostrovok.store`) — pageerror на каждом открытии;
  локально на dev-сервере — полный diff: `<a>` не может быть потомком `<a>`,
  стек `EventCard → EventDetailsPanel-карточка → teacher-Link`.
- **Фикс (эта ветка):** паттерн «stretched link» — пустой якорь деталей
  `absolute inset-0` с `aria-label` и `data-event-id`; контент карточки
  `pointer-events-none relative z-10`; ссылка преподавателя
  `pointer-events-auto` (кликабельна поверх, ведёт в `/people/<teacher>` —
  контракт DIG-37 и e2e `e2e/people.spec.ts` сохранён); возврат фокуса по Esc
  (`[data-event-id]`) сохранён; `data-testid="day-card-<id>"` перенесён на
  `<li>` (ссылка преподавателя остаётся потомком карточки).
- **Тесты (red-first):** `tests/schedule-card-nested-links.test.tsx` — до фикса
  3/4 красные («найдены вложенные `<a>`»), после — зелёные; контракты
  `tests/schedule-screen.test.tsx` обновлены на stretched-link; смежные
  наборы (schedule-page-day-month, micro-animations, i18n-en-surfaces,
  voice-assistant-components) — зелёные (96 тестов).
- **Верификация фикса в браузере:** `dig-104-fix-verify.mjs` — гидрация
  `/schedule`, `?view=day`, `?view=week` чистая; клик карточки → `?event=` и
  панель деталей; Esc → фокус на карточке; клик по преподавателю →
  `/people/teacher-orlov`. Контрактные e2e против фикса — зелёные:
  `e2e/schedule-event-details.spec.ts` (Esc → фокус, панель, 404-изоляция, ICS)
  и `e2e/people.spec.ts` (переход из карточки пары в справочник) — оба проекта
  desktop-1440/mobile-360, exit 0.

### F-3 · HIGH · «Прослушать день»: server/client ветка в рендере (вторая причина #418 на тех же маршрутах)

- **Что:** `ListenDayButton` (DIG-65) вызывал `isSpeechSynthesisSupported()`
  в рендере. SSR (без `window`) рисовал `null`, браузер со `speechSynthesis` —
  кнопку `<button data-testid="listen-day">` перед лентой пар. Первый рендер
  клиента расходился с серверной разметкой → React #418. На проде этот дефект
  стрелял вместе с F-1 на одних и тех же маршрутах (один pageerror на визит
  не различает причины); локально после фикса F-1 ошибка оставалась и была
  воспроизведена с полным diff (`<button listen-day>` vs `<ol mobile-day-list>`).
- **Где:** `src/components/schedule/listen-day-button.tsx` — guard
  `if (!enabled || !isSpeechSynthesisSupported()) return null;` в теле рендера.
- **Серьёзность:** HIGH — гидрация мобильного вида расписания падала у всех
  студентов с включённой озвучкой (дефолт `voiceAssistant = true`).
- **Фикс (эта ветка):** доступность движка читается через `useSyncExternalStore`
  (серверный снапшот — всегда `false`, клиентский — по наличию
  `window.speechSynthesis`): первый рендер всегда без кнопки, SSR и клиент
  совпадают, кнопка появляется после гидрации в браузере с движком.
- **Тесты (red-first):** `tests/listen-day-hydration.test.tsx` —
  `renderToString` (эффекты не выполняются) не должен содержать кнопку:
  до фикса красный (кнопка в SSR-строке при наличии движка), после — зелёный;
  поведение пост-монтирования (есть движок → кнопка; нет → нет) покрыто.
  Существующие контракты DIG-65 (`tests/voice-assistant-components.test.tsx`,
  13 тестов) зелёные без изменений.
- **Верификация:** см. `dig-104-fix-verify.mjs` (гидрация `/schedule` и
  `?view=day` чистая после обоих фиксов).

### F-2 · INFO · Ложное срабатывание MSK-проверки в виде «месяц» на 360 px (артефакт проверки, не продукта)

  странице есть, 20 ноября подсвечено как «сегодня» — МСК корректен.
  Продукт прав; исправлена сама проверка sweep-скрипта (для сетки месяца —
  сравнение именительного названия месяца без учёта регистра).
- **Серьёзность:** INFO (продуктового дефекта нет).
