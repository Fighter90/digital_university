# cabinet-i18n Specification

## Purpose
Английская локализация ключевых поверхностей кабинета: рендер по локали сессии, словари, локале-параметричные хелперы и документы (PDF).
## Requirements
### Requirement: Ключевые страницы кабинета рендерят контент по локали

Требование «Ключевые страницы кабинета рендерят контент по локали» — обязательное (MUST): Переключение локали (`du-locale`) переводит основной контент ключевых страниц:
сводка успеваемости `/grades`, зачётная книжка `/grades/gradebook`, выписка из
зачётки (PDF `/api/grades/transcript`) и карточка заявки `/requests/[номер]`.

#### Scenario: EN-сводка успеваемости без русских строк контента

- **WHEN** студент с локалью `en` открывает `/grades`
- **THEN** пилюли семестров, блок среднего балла (включая дельту
  «vs Spring 25/26»), кредиты, рейтинг группы, светофор, карточки дисциплин
  (словесные пороги, бейджи допуска), долги и пустые/ошибочные состояния
  отрендерены на английском
- **AND** демо-контент (ФИО, названия дисциплин) остаётся на русском

#### Scenario: RU-рендер байт-в-байт прежний

- **WHEN** локаль `ru` (дефолт, в т.ч. без cookie)
- **THEN** все строки экранов совпадают с прежними байт-в-байт
  (юнит-снимки и e2e не меняются)

### Requirement: Выписка PDF собирается по локали сессии

Требование «Выписка PDF собирается по локали сессии» — обязательное (MUST):

#### Scenario: EN-выписка

- **WHEN** студент с локалью `en` скачивает `/api/grades/transcript`
- **THEN** заголовок, шапка студента, колонки таблицы, итоги семестров,
  блок проверки подлинности — на английском (глифы латиницы покрыты
  векторным шрифтом)

### Requirement: Карточка заявки локализует статусы и подписи

Требование «Карточка заявки локализует статусы и подписи» — обязательное (MUST):

#### Scenario: EN-карточка заявки «ЗД-…»

- **WHEN** студент с локалью `en` открывает карточку канонической заявки
- **THEN** статус-пилюля, «подана», «Готовность до», «Ведёт», алерты
  доработки/отказа, блок документа, параметры и вложения мастера, заголовки
  «Параметры заявки»/«Вложения»/«История заявки» — на английском;
  таймлайн пересобирает подписи переходов по словарю

### Requirement: Хелперы presentation-слоя локале-параметричны

Требование «Хелперы presentation-слоя локале-параметричны» — обязательное (MUST): Существующие чистые хелперы принимают необязательный хвостовой параметр
`locale = 'ru'`; вызовы без параметра и RU-тесты остаются валидными.

#### Scenario: EN-подписи хелперов

- **WHEN** хелпер вызван с `'en'`
- **THEN** подпись строится по словарю EN (`semesterShortLabel` →
  «Fall 26/27», `bestPercentLabel(1, 1)` → «You are the only student in the
  group», `trafficLight` → «All good», выписка → «Academic transcript»)

### Requirement: Главная (/dashboard) рендерится по локали

Требование «Главная (/dashboard) рендерится по локали» — обязательное (MUST): Hero (приветствие по времени суток, «Ваша неделя», дата, сводка недели),
плитки (средний балл, кредиты, долги, заявки в работе), виджеты «Сегодня»,
«Ближайшие дедлайны», «Что от меня ждут», «Как у меня дела», «Заявки»,
«Новости деканата», «Мероприятия», быстрые действия, скелетон загрузки и
пустые состояния берут строки из словарей по локали `du-locale`.

#### Scenario: EN-рендер hero и виджетов без кириллицы

- **WHEN** студент с локалью `en` открывает `/dashboard`
- **THEN** hero, плитки и виджеты отрендерены на английском
  («Your week», «Good afternoon», «GPA», «of 240», «total requests: 3»,
  «No classes today», «Next study day — …»)
- **AND** автотест «no Cyrillic on EN render» по рендеру карточек зелёный

#### Scenario: RU-рендер байт-в-байт прежний

- **WHEN** локаль `ru` (дефолт)
- **THEN** строки hero/плиток/виджетов совпадают с прежними захардкоженными
  (пинются юнит-тестом 5-й секции приёмки)

### Requirement: Расписание (/schedule) рендерится по локали

Требование «Расписание (/schedule) рендерится по локали» — обязательное (MUST): Виды «День/Неделя/Месяц», переключатель и URL-стрелки, карточка пары
(аудитория, бейджи «Перенос/Отмена», «было: …», «до {время}»), aria-подписи
карточек, панель деталей пары (тип, дата, аудитория/корпус, блок переноса
«Было → Стало», автор «деканат»), пустые состояния («Ближайшие пары»,
«В семестре пар больше нет»), мини-календарь и подписи семестра локализованы.

#### Scenario: EN-форматы дат по правилам локали

- **WHEN** локаль `en`
- **THEN** даты отрендерены в en-US-порядке: «Thu, November 12»,
  «Wednesday, November 11», «November 2026», «November 9 – 15, 2026»,
  «Fall semester 2026/27»; RU-форматы («чт, 12 ноября», «9 – 15 ноября 2026»)
  не меняются

#### Scenario: EN-«было» и aria без кириллицы

- **WHEN** пара перенесена (ROOM_CHANGED/TIME_CHANGED) и локаль `en`
- **THEN** карточка и недельная модель показывают «was: room 214 / 11:10»
  (строчная форма части «было»), aria-подпись — «…, rescheduled»; панель
  деталей — «room 214», автор «the deanery»

### Requirement: Заявки (/requests) рендерятся по локали

Требование «Заявки (/requests) рендерятся по локали» — обязательное (MUST): Список заявок (фильтры-корзины, поиск, карточка: статус-пилюля, «подана»,
строка следующего действия, кнопки действий), горизонтальный степпер
(подписи канона и aria), мастер заказа (шаги «Что нужно / Параметры /
Проверка», подсказки типов, бейджи «Мгновенно/срок», лимит вложений, диалог
«Выйти без сохранения?») и форма вопроса по заявке локализованы.

#### Scenario: EN-карточка заявки без кириллицы, включая номер

- **WHEN** локаль `en` и канонический номер заявки «ЗД-2026-000123»
- **THEN** карточка (включая sr-only aria) показывает номер транслитом
  «ZD-2026-000123»; ссылки ведут на канонический номер (роут и поиск
  не меняются); RU-рендер показывает «ЗД-…» как прежде

#### Scenario: EN-мастер заказа без кириллицы

- **WHEN** студент с локалью `en` открывает `?order=new`
- **THEN** заголовок, «Step 1 of 3 · What you need», названия/подсказки
  типов, бейдж «Instant», способ получения и лимит файлов — на английском
  (юнит-рендер через Portal в jsdom без кириллицы)

### Requirement: Контент-каталоги и ассистент доступны на английском

Требование «Контент-каталоги и ассистент доступны на английском» — обязательное (MUST): На локали `en` страницы `/guide`, `/help` (включая статью, категории, поиск),
`/ai-assistant` (чат, карточки действий, приветствие, fallback, подсказки) и
`/mcp` рендерятся полностью на английском; кириллица в видимом рендере
отсутствует. Демо-контент (ФИО, названия дисциплин) может оставаться RU.

#### Scenario: EN-рендер страницы справки

- **WHEN** cookie `du-locale=en`, пользователь открывает `/guide`
- **THEN** заголовок, интро, оглавление, все разделы, шаги, ссылки и callout'ы
  на английском; поиск фильтрует EN-разделы

#### Scenario: EN-статьи и поиск базы знаний

- **WHEN** cookie `du-locale=en`, пользователь открывает `/help`
- **THEN** популярные запросы, категории и статьи на английском; EN-запрос
  («scholarship») находит EN-статьи; ноль результатов показывает EN-пустое
  состояние с двумя следующими действиями

#### Scenario: EN-чат ассистента

- **WHEN** cookie `du-locale=en`, пользователь открывает `/ai-assistant`
- **THEN** приветствие, подсказки, кнопки, дисклеймер, ответы всех намерений,
  карточки действий и fallback попапа — на английском

#### Scenario: EN-страница MCP

- **WHEN** cookie `du-locale=en`, пользователь открывает `/mcp`
- **THEN** секции документации, каталог инструментов, шаги подключения,
  примеры вопросов и JSON-конфиг (плейсхолдер токена «YOUR_TOKEN» в угловых
  скобках) — на английском

### Requirement: RU — канон без изменений

Требование «RU — канон без изменений» — обязательное (MUST): Все прежние RU-строки интерфейса и контент-каталогов равны прежним
байт-в-байт; EN-словарь и EN-каталоги не содержат кириллицы (кроме
осознанно двуязычных ключей `locale.*`).

#### Scenario: RU-рендер не меняется

- **WHEN** cookie `du-locale` отсутствует или `ru`
- **THEN** рендер четырёх поверхностей и попапа совпадает с прежним
  (существующие юнит-тесты зелёные без правок контента)
