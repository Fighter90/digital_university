# a11y Specification

## Purpose
Специальная версия кабинета для слабовидящих: plain-режим без стилей и с крупным шрифтом по ссылке в футере, без зависимости от основной вёрстки.
## Requirements
### Requirement: Plain-версия для слабовидящих по ссылке

Требование «Plain-версия для слабовидящих по ссылке» — обязательное (MUST): Режим «Версия для слабовидящих» (plain) включается ссылкой в двух местах
сразу на кабинете и на лендинге: полоска-ссылка НАД шапкой и ссылка со
значком Eye в футере. Ссылка — форма с server action `toggleA11yVersion`
(работает без JavaScript): в обычном режиме подпись «Версия для слабовидящих»
(EN «Accessibility version»), в plain — «Обычная версия» (EN «Standard
version») в тех же местах. Состояние — cookie `du-a11y-version` владельца
сессии (`plain` | `off`); действие owner-scoped (анонимный посетитель
выпадает на /login, IDOR невозможен). Необязательное поле `next` принимает
только внутренние пути «/…» — открытый редирект исключён.

#### Scenario: Включение plain-версии по полоске

* WHEN владелец сессии нажимает полоску «Версия для слабовидящих» над шапкой
* THEN server action записывает cookie `du-a11y-version=plain` и
  перевалидирует каркас
* WHEN значение из формы не входит в whitelist (`plain`, `off`)
* THEN cookie не меняется, вызов не падает

#### Scenario: Обратная ссылка в тех же местах

* WHEN интерфейс в plain-режиме
* THEN полоска над шапкой и ссылка в футере подписаны «Обычная версия» /
  «Standard version» и возвращают `du-a11y-version=off`

### Requirement: Класс a11y-plain на <html>

Требование «Класс a11y-plain на <html>» — обязательное (MUST): Root layout читает cookie `du-a11y-version` и добавляет на `<html>` класс
`a11y-plain` server-side, до первой отрисовки, на всех страницах (кабинет,
лендинг, вход; нет/битая cookie — класса нет). Класс добавляется к классам
appearance (DIG-44) и режимам DIG-86 — сосуществуют, plain приоритетнее.

#### Scenario: Cookie → класс до первой отрисовки

* WHEN root layout рендерится с cookie `du-a11y-version=plain`
* THEN `<html>` содержит класс a11y-plain (вместе с a11y-large-text /
  a11y-no-effects, если включены режимы DIG-86)
* WHEN cookie нет, `off` или битая
* THEN класса a11y-plain на `<html>` нет

### Requirement: CSS plain-режима в globals.css

Требование «CSS plain-режима в globals.css» — обязательное (MUST): Слой `.a11y-plain` — в самом конце globals.css, вне декоративной системы:
белый фон, чёрный текст, синие (#0000ee) подчёркнутые ссылки, шрифт с
засечками (Georgia) и корень 20px (базовый текст ≥20px; text-xs/sm и
частые произвольные размеры — не меньше базы), линейная колонка вместо
сеток (`.grid` → один столбец, контентные `.flex` → колонка; шапка, футер
и фиксированные панели остаются строками), поля форм — белый фон с чёрной
рамкой 2px, разделители — чёрные border вместо теней, без анимаций,
переходов, теней, градиентов и фоновых заливок. Media-блок 360px даёт
цели нажатия ≥44px и убирает горизонтальные «хвосты» полоски. Plain
перекрывает тему/размер шрифта (DIG-44), режимы DIG-86 и системный
prefers-reduced-motion, включая их поведение (reveal-секции видимы сразу).

#### Scenario: Plain перекрывает прочие режимы доступности

* WHEN включён plain вместе с «Крупный текст и без эффектов» (DIG-86) и/или
  системным prefers-reduced-motion
* THEN действует оформление plain: белый фон, чёрный текст, serif 20px,
  без анимаций — контент никогда не скрыт (reveal видим без JS-наблюдателя)

#### Scenario: Plain на мобайле 360px

* WHEN вьюпорт ≤360px
* THEN правила plain действуют без исключений, кнопки и ссылка версии —
  цели нажатия ≥44px, полоска без горизонтального переполнения
