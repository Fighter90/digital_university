# voice-assistant Specification

## Purpose
Голосовые функции: озвучка дня, голосовой ввод в AI-гиде, отключение в настройках с персистентностью, деградация без браузерной поддержки.
## Requirements
### Requirement: Запасное поведение «Прослушать день»

Требование «Запасное поведение «Прослушать день»» — обязательное (MUST):

#### Scenario: Браузер содержит speechSynthesis
- **WHEN** браузер содержит speechSynthesis, но голосовые движки недоступны (озвучка не стартовала) **THEN** в течение ~1.2 с появляется запасное сообщение role="status" «Голосовой движок недоступен…», кнопка возвращается в исходное состояние; молчаливое «ничего не произошло» запрещено.

#### Scenario: SpeechSynthesisUtterance бросает исключение
- **WHEN** SpeechSynthesisUtterance бросает исключение
- **THEN** показывается то же запасное сообщение.

### Requirement: Озвучка выбранного дня расписания

Требование «Озвучка выбранного дня расписания» — обязательное (MUST): Вид «День» экрана «Расписание» (десктоп) и мобильный вид дня показывают
кнопку «Прослушать день». По клику день озвучивается браузерным
синтезом речи (SpeechSynthesis, ru-RU): дата и «сегодня», число пар,
каждая пара — дисциплина, тип, время, аудитория («ауд. N» читается как
«аудитория N», «онлайн» — как есть) и преподаватель. Отменённые пары не
озвучиваются; день из одних отмен — «Все пары на этот день отменены»;
пустой день — «Пар в этот день нет»; перенесённая пара помечается
«пара перенесена». Повторный клик останавливает озвучку (aria-pressed
переключается), уход со страницы отменяет озвучку.

#### Scenario: День с парами озвучивается по кнопке

* WHEN студент на виде «День» нажимает «Прослушать день»
* THEN синтезу передаётся текст с датой, числом пар и описанием каждой
  не-отменённой пары (дисциплина, тип, время, аудитория, преподаватель)

#### Scenario: Отменённые пары не читаются, перенос помечается

* WHEN в дне есть отменённая и перенесённая пары
* THEN отменённая пара не входит в текст озвучки,
  перенесённая — с пометкой «пара перенесена»

#### Scenario: Повторный клик останавливает озвучку

* WHEN студент нажимает кнопку во время озвучки
* THEN синтез останавливается и кнопка возвращается в состояние
  «Прослушать день» (aria-pressed=false)

### Requirement: Голосовой ввод в AI-гиде

Требование «Голосовой ввод в AI-гиде» — обязательное (MUST): В форме свободного вопроса AI-гида рядом с полем есть кнопка-микрофон.
Распознавание выполняет браузер (Web Speech API, ru-RU); финальная
расшифровка дописывается в поле вопроса. В браузере без поддержки
SpeechRecognition кнопка не отрисовывается. Сказанный текст никуда на
сервер не отправляется и не сохраняется — только в поле ввода.

#### Scenario: Диктовка попадает в поле вопроса

* WHEN студент нажимает микрофон и браузер возвращает расшифровку
* THEN расшифровка дописана в поле вопроса гида

#### Scenario: Браузер без SpeechRecognition

* WHEN браузер не поддерживает SpeechRecognition
* THEN кнопка-микрофон не отрисовывается

### Requirement: Голосовые функции отключаемы в настройках

Требование «Голосовые функции отключаемы в настройках» — обязательное (MUST): На вкладке «Вид» экрана «Настройки» есть карточка «Голосовой ассистент»
с переключателем «Озвучка и голосовой ввод» (по умолчанию включён).
Переключение сохраняется в настройках студента server action'ом
(скоуплен сессией; сотруднику недоступен) и применяется ко всему
кабинету сразу: выключено — кнопка «Прослушать день» и микрофон гида
скрыты, включено — возвращаются. Состояние переживает перезагрузку и
повторный вход. Студент без записи настроек получает включённое
состояние (fail-soft дефолт); сотруднику кабинета голосовые функции
не показываются.

#### Scenario: Выключение сохраняется и скрывает функции

* WHEN студент выключает «Озвучка и голосовой ввод» на вкладке «Вид»
* THEN после перезагрузки переключатель остаётся выключенным
* AND кнопка «Прослушать день» на виде «День» и микрофон в AI-гиде
  не отрисовываются

#### Scenario: Включение возвращает функции

* WHEN студент снова включает переключатель
* THEN кнопка озвучки на «Дне» и микрофон гида снова отрисовываются

### Requirement: Деградация без поддержки браузера

Требование «Деградация без поддержки браузера» — обязательное (MUST): Кнопка «Прослушать день» не отрисовывается, если у браузера нет
`speechSynthesis`; микрофон — если нет `SpeechRecognition`. Функции не
выбрасывают ошибок в браузерах без Web Speech API и на сервере
(SSR-safe детекторы).

#### Scenario: Браузер без speechSynthesis

* WHEN страница расписания открыта в браузере без speechSynthesis
* THEN кнопка «Прослушать день» не отрисовывается и ошибок нет

### Requirement: Переключатель «Озвучка и голосовой ввод» отражает сохранённое состояние

Требование «Переключатель «Озвучка и голосовой ввод» отражает сохранённое состояние» — обязательное (MUST): Вкладка «Вид» (/settings) рендерит карточку «Озвучка и голосовой ввод» с
переключателем (role=switch, aria-label «Озвучка и голосовой ввод»). Состояние
переключателя синхронизировано с персистентной строкой настроек студента
(StudentSettings.voiceAssistant), а не с локальным оптимистичным состоянием.

#### Scenario: Включение переживает перезагрузку

- **WHEN** студент включает переключатель «Озвучка и голосовой ввод»
- **AND** server action `saveVoiceAssistantAction(true)` завершается успешно
  (строка StudentSettings перезаписана, voiceAssistant=true)
- **AND** студент перезагружает страницу /settings?tab=appearance
- **THEN** переключатель рендерится с `aria-checked="true"`
- **AND** голосовые функции кабинета («Прослушать день», микрофон AI-гида)
  снова доступны.

#### Scenario: aria-checked не опережает запись

- **WHEN** студент переключает тумблер
- **THEN** `aria-checked` меняется не раньше успешного завершения
  `saveVoiceAssistantAction` (пока action в полёте — состояние предыдущее,
  статусная строка показывает «Сохранение…»).

#### Scenario: Отказ сохранения откатывает переключатель

- **WHEN** `saveVoiceAssistantAction` возвращает false (не студент, сбой слоя
  данных, невалидный аргумент)
- **THEN** переключатель остаётся в исходном (сохранённом) состоянии
- **AND** статусная строка сообщает об ошибке сохранения; значение в БД не
  изменилось.
