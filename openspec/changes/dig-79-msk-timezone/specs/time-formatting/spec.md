# Delta: время прототипа — одна зона Europe/Moscow (DIG-79)

## ADDED Requirements

### Requirement: Форматирование времени независимо от пояса машины

Требование «Форматирование времени независимо от пояса машины» — обязательное (MUST): Модули представления времени (`session-format`, `notification-view`, `ics`,
`quiet-hours`) обязаны вычислять настенные компоненты (год/месяц/день/час/
минута) в явной зоне `Europe/Moscow` и выдавать одинаковые строки на сервере
и в браузере при любом поясе машины.

#### Scenario: Время пары на сервере в UTC

- **WHEN** экзамен начинается в момент `2026-11-18T10:00:00.000Z`
  (= 13:00 МСК) и сервер работает в UTC
- **THEN** `formatSessionTime` возвращает `13:00`, а не `10:00`

#### Scenario: Граница суток по московскому календарю

- **WHEN** уведомление создано в `2026-11-17T21:30:00.000Z`
  (= 00:30 МСК 18 ноября) и «сейчас» `2026-11-18T12:00:00.000Z`
- **THEN** `groupNotificationsByDay` относит его к группе `Сегодня`
  (по UTC-календарю было бы «Вчера»)

#### Scenario: Гидрация сервер/клиент

- **WHEN** один и тот же момент форматируется дважды (как SSR-сервером, так
  и браузером в любой зоне)
- **THEN** строки совпадают байт в байт (двойного источника рендера нет,
  React #418 по времени не воспроизводится)

### Requirement: Плавающее время ICS по Москве

Требование «Плавающее время ICS по Москве» — обязательное (MUST):

#### Scenario: DTSTART экзамена в 13:00 МСК

- **WHEN** `icsDateTime(2026-11-18T10:00:00.000Z)`
- **THEN** результат `20261118T130000` независимо от пояса машины

### Requirement: Тихие часы по московской минуте суток

Требование «Тихие часы по московской минуте суток» — обязательное (MUST):

#### Scenario: Окно через полночь

- **WHEN** окно 22:00–08:00 и «сейчас» `2026-11-18T21:30:00.000Z`
  (= 00:30 МСК 19 ноября)
- **THEN** `isWithinQuietHours` возвращает `true` (по UTC-часам было бы `false`)

### Requirement: Контейнер приложения живёт по Москве

Требование «Контейнер приложения живёт по Москве» — обязательное (MUST):

#### Scenario: compose

- **WHEN** читается `deploy/docker-compose.yml`
- **THEN** сервис `app` объявляет переменную окружения
  `TZ: Europe/Moscow` (сид и серверная логика создают московские настенные
  времена; прод-UTC больше не сдвигает расписание на +3 часа)
