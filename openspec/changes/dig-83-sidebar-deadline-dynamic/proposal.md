# Proposal: сайдбар «Ближайший дедлайн» — динамический срок (DIG-83, BUG-06)

## Зачем

QA-регресс 18.11.2026 (BUG-06, средний): карточка сайдбара «Ближайший дедлайн»
показывала «Курсовая работа по базам данных · до 20 ноября · осталось 9 дней»
при текущей дате 18 ноября (реально — 2 дня). Соседняя карточка «Дедлайны» на
той же странице показывала корректное «осталось 2 дня». Причина: в сайдбаре
был свой дублирующий источник срока, а после первого фикса (коммит 67b8bac)
— собственная логика `ceil((due − Date.now())/24ч)` с локальной плюрализацией,
которая не совпадает с карточкой дашборда: зависит от времени суток, ломает
плюрализацию на 0 («осталось 0 дня») и пишет «остался 1 день» вместо
«Завтра» — соседние карточки одной страницы показывают разные сроки.

## Что

- `src/lib/dashboard-format.ts`: экспорт `calendarDaysLeft(due, now)` —
  разница календарных дней в явной зоне Europe/Moscow (Москва = UTC+3
  без перехода на летнее время). Логика совпадает с серверной
  `calendarDaysLeft` карточки «Дедлайны», но детерминирована SSR/гидрацией
  при любом TZ процесса (конвенция BUG-02, tests/msk-timezone.test.ts).
- `src/components/shell/side-nav.tsx`: срок карточки сайдбара считается
  той же логикой, что карточка «Дедлайны» — `calendarDaysLeft` +
  общий `daysLeftLabel` (0 → «Сегодня», 1 → «Завтра», N → «осталось N…»);
  дата дедлайна задана в явной зоне (`2026-11-20T00:00:00+03:00`),
  текст даты — через `formatLongDate`. Дублирующий источник (собственная
  плюрализация + `Date.now()`) удалён.
- Юнит-тест `tests/side-nav-deadline.test.tsx`: срок от фиксированного
  «сегодня» (fake timers), TZ процесса UTC/America_New_York — строки
  байт-в-байт одинаковы.

## Non-goals

- Не трогаем серверные `calendarDaysLeft` (dashboard/tasks/performance/
  session-format) — их объединение отдельная задача по рефакторингу.
- Не делаем дедлайн сайдбара «катящимся» (из реальных задач студента) —
  данные вымышленные, подключение реальных задач за DIG-21+.
- После дедлайна счётчик прижимается к «Сегодня» (демо-дата фиксированная
  20.11.2026; плашка DIG-14 не исчезает, e2e каркаса остаётся зелёным).
