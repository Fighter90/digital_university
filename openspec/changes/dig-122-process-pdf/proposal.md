# Proposal: PDF «Описание процесса создания» — закрыть чек-лист брифа (DIG-122)

## Зачем

PDF `docs/submission/digital-deanery-process.pdf` (ред. 1, DIG-94) закрывал
чек-лист задания не полностью, а в одном месте — неточно:

1. **Опрос однокурсников.** Текст «Мы спросили студентов, что они решают чаще
   всего» — неправда: задача DIG-17 (анкета 15–30 ответов) отменена 16.11.2026,
   опрос не проводился. Жюри обязано видеть честную альтернативную проработку
   (сценарии, справка/FAQ, доступность) и явное ограничение.
2. **Перечень инструментов неполон:** отсутствовал Higgsfield (дизайн/иллюстрации
   — критерий конкурса «ИИ-инструменты для дизайна», промпты в
   `docs/ai-log/assets.md`), sharp/SVG-оверлеи.
3. **Скриншоты без неудачных вариантов.** Бриф прямо ждёт «работу с ошибками
   ИИ»: ревью RETURN×3 (DIG-20), красные гейты/гонка кук (DIG-77),
   squash-регрессия PR #82 (bcffd8a), OOM-kill (DIG-50) — лучший материал
   проекта, его не было.
4. **Цифры устарели:** «75 PR» → 83 слито; состав задач Linear изменился
   (125 всего, 100 закрыто, 10 отменено; 77 циклов в ai-log).

> **Раунд 3 (ревью):** цитаты дословно сверены с источниками (`.opencode/agent/*.md`,
> `docs/ai-log/assets.md`, git log) с честными «…» на обрывах; счётчики обновлены
> по срезу на 20.11 (104 закрыто, 86 merged PR) и помечены датой среза;
> подпись login-hero = реальный размер файла. Детали — tasks.md §9, тест
> `tests/submission-pdf-facts.test.ts`.
5. PDF собирался без исходника — пересборка была невозможна.

## Что делаем

1. **PDF пересобран (ред. 2, 11 стр.)** из нового воспроизводимого исходника
   `docs/submission/process.html` (Inter OFL в `docs/submission/fonts/`)
   скриптом `docs/submission/build-pdf.mjs` (Playwright Chromium → A4).
2. **Секция 1** — честный блок об отменённом опросе DIG-17 + альтернативная
   проработка: сценарии «что сегодня / как дела / нужна справка / что
   изменилось», справка и база знаний, доступность, зафиксированное ограничение.
3. **Секция 2** — полный перечень инструментов: + Higgsfield (Recraft V4.1
   Flash, Z Image), sharp+SVG; уточнены цифры Linear/PR; IDE = OpenCode CLI.
4. **Секция 3** — промпты по этапам: постановка задачи (DIG-76), чек-лист
   ревьюера, чек-лист security, механика fail-closed (VERDICT/SECURITY_VERDICT,
   meta-verdict clerk), промпт иллюстрации Higgsfield + результат (hero входа),
   диалог вместо промпта (EN-локализация в 3 части, P0-регресс).
5. **Секция 4** — скриншоты: ранние макеты → мастер заявки (неудачный вариант
   «одна длинная форма» виден на скриншоте) → кабинет RU/EN.
6. **Новая секция 5** «Работа с ошибками ИИ»: RETURN×3 (DIG-20), красные гейты
   и гонка кук (DIG-77), squash-регрессия PR #82 с git-панелью (bcffd8a,
   54 файлов, +825/−438), OOM-kill и reflog-rescue (DIG-50). Панели — дословные
   выдержки из журналов и коммитов, воспроизведённые типографикой.
7. **Секции 6–7** — защита простыми словами (argon2id, `__Host-`cookie,
   owner-scope/IDOR, .env, rate-limit) и ручные этапы (деплой, сид, регресс,
   Timeweb, видео, сборка PDF) — сохранены из ред. 1, дополнены.
8. **Секция 8** — актуальные цифры (125/95/83/77, 20+, RU/EN, 29 скриншотов,
   360 px) + блок «где проверить каждое утверждение».
9. **Сопутствующие документы** синхронизированы: `docs/SUBMISSION.md`,
   `docs/submission/COMMENT.md` — описание PDF упоминает неудачные варианты
   и честный блок об опросе.

## Non-goals

- Не меняем продукт, тесты, `scripts/swarm/` (инфраструктура роя), деплой.
- Не проводим опрос однокурсников (отменён осознанно, DIG-17; вне срока).
- Не прикладываем ретро-скриншоты несуществующих экранов: «неудачные варианты»
  показаны дословными выдержками из журналов/git, с явной пометкой об этом.

## Ограничения

- Все данные вымышленные; цитаты промптов и вердиктов — дословные из
  `docs/ai-log/`, `.opencode/agent/*.md`, git-истории; секретов нет.
- PDF ≤ 4 МБ, читается жюри за ~5 минут (11 стр., крупная типографика).
