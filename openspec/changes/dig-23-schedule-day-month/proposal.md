# Proposal: Расписание — виды «День» и «Месяц», мобильный вид с лентой дат (DIG-23)

## Зачем

После серверной части (DIG-21) экран `/schedule` остаётся заглушкой: студент
не видит ни списка пар на день, ни календаря месяца. По Figma
«04 · Расписание — день / месяц» и мобильному варианту (360 px, M3) нужны
вид «День» (карточки пар с бейджами переноса/отмены), вид «Месяц»
(сетка 7×N с цветными точками пар) и мобильный вид — горизонтальная лента
дат недели со свайпом и компактным списком недели. Прототип отвечает на
вопрос «а как студент смотрит расписание на телефоне, если недельная сетка
не влезает?»

## Что

- `src/lib/schedule-cards.ts` — чистая вью-логика (без серверных импортов,
  юнит-тесты): серийализуемая модель карточки пары `ScheduleEventCard`
  (структурно совместима с моделью недели DIG-22 — один сериализатор на оба
  вида), `LESSON_KIND_META` (пилюля/точка/полоса по токенам DIG-13),
  форматирование дат («чт, 12 ноября», «Среда, 11 ноября», «Ноябрь 2026»),
  разбор параметров URL `?view` / `?date` / `?month` (мусор → день/сегодня/
  текущий месяц), `neighborDay` (листание с клампом по семестру),
  `weekWindow` (окно ±2 недели для мобильной ленты и свайпа),
  `monthCellViews` (сетка целыми неделями с понедельника, «сегодня»,
  точки пар до 4 + «+N»), `ribbonWeekDays` (неделя выбранного дня),
  `swipeDirection` (горизонтальный свайп с порогом 48 px).
- Общие компоненты (`src/components/schedule/`): `EventTypePill`
  (пилюля типа с цветом токенов), `EventCard` (время слева, цветная полоса
  типа, название, аудитория/онлайн, преподаватель, ЗАМЕТНЫЕ бейджи «Перенос»
  (штриховка + warning) и «Отмена» (зачёркнутое название + error), строки
  «было: ауд./время» и причина) — одна карточка для десктопного дня,
  мобильного дня и компактной недели; `DayView` (заголовок дня, стрелки-
  соседи, «Сегодня», пустой день с иллюстрацией и «Ближайшие пары: …»),
  `MonthView` (навигация по месяцам, сетка 7×N, клик по дню → вид «День»),
  `MobileSchedule` (лента дат недели, автоскролл к выбранному дню внутри
  своего контейнера, свайп влево/вправо листает дни, режим «неделя» —
  компактный список по дням), `ViewSwitcher` (День/Неделя/Месяц через URL).
- `Segmented` (DIG-13) расширен опцией `disabled` (тем же патчем, что и
  DIG-22): «Неделя» на десктопе недоступна до merge недельной сетки.
- Страница `/schedule`: `?view=day` (по умолчанию) / `?view=week`
  (десктоп — честная заглушка, мобильный — компактный список) /
  `?view=month`; данные читает только сервер (`getSchedule` окном ±2 недели,
  `getMonth`, `getNextStudyDay` для пустых дней), контекст — живая сессия,
  IDOR невозможен по построению; STAFF — явная заглушка; ошибка слоя данных —
  ErrorState.

## Риски

- С веткой DIG-22 (недельный вид, отдельная ветка) пересекаются
  `page.tsx` и `Segmented` — правка `Segmented` повторяет патч DIG-22
  байт-в-байт, страница структурирована так, чтобы вид «Неделя» подставлялся
  заменой одной ветки рендера.
