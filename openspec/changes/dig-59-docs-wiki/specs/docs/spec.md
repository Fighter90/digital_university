# docs — delta (DIG-59)

## ADDED Requirements

### Requirement: Справка студента (docs/help.md)

В документации репозитория есть файл `docs/help.md` — справка студента,
закрывающая сценарии: вход и сеансы, главная с виджетами, расписание
(день/неделя/месяц, переносы), успеваемость («как у меня дела», зачётка,
сессия, пересдачи, апелляция), заявки и справки (каталог, заказ, статусы),
справка с QR (код проверки, PDF, публичная проверка /verify/<код>, отзыв),
уведомления (каналы, тихие часы, счётчик непрочитанных), поиск ⌘K и
настройки. Для разделов, чей экран ещё не реализован, справка честно
помечает статус «в разработке».

#### Scenario: Справка отвечает на вопрос «как получить справку с QR»

* WHEN читатель открывает `docs/help.md`
* THEN в файле есть раздел про заявки и справки с описанием статусов
  («Подана», «В работе», «Требует правок», «Выполнена», «Отклонена»)
* AND есть раздел «Справка с QR»: код проверки, PDF, проверка
  /verify/<код> без входа, отзыв сотрудником

### Requirement: Справка по цифровому ассистенту (docs/assistant.md)

В документации есть `docs/assistant.md`: роль ассистента, где он доступен
(пункт меню, FAB на мобильном, хэндоффы с параметрами `?q=` / `?intent=`),
возможности, примеры запросов, ограничения демо-режима и MCP-интеграции
(Product Hunt, Календарь, Деканат-API): что даёт каждый сервер, шаги
подключения, правила обращения с (демо-)токенами. Все данные вымышленные —
в документе есть явная пометка.

#### Scenario: Справка ассистента объясняет MCP-интеграции

* WHEN читатель открывает `docs/assistant.md`
* THEN в файле описаны все три сервера каталога MCP
  (`src/lib/mcp-servers.ts`) по именам: Product Hunt, Календарь,
  Деканат-API
* AND указано, что токены демонстрационные и реальных ключей нет

### Requirement: Индекс документации в README

README содержит раздел быстрых ссылок на документацию (help, assistant,
architecture, security, deploy, figma-screens, SDD-гайд, CHANGELOG,
ai-log) и раздел скриншотов (готовые снимки desktop-1440 и mobile-360).
Плашка «Концепт для конкурса» в начале README сохраняется.

#### Scenario: README ведёт на новые разделы

* WHEN читатель открывает README
* THEN он находит ссылки на docs/help.md и docs/assistant.md
* AND ссылки на скриншоты desktop-1440 и mobile-360

### Requirement: Перекрёстные ссылки из кабинета

Кабинет ссылается на документацию через единый модуль `src/lib/docs-links.ts`
(абсолютные GitHub-ссылки, ветка main). Страница `/settings?tab=home`
показывает карточку «Справка и документация» со ссылками на все три
документа; справка MCP на `/settings?tab=mcp` и страница `/ai-assistant`
ведут на `docs/assistant.md`.

#### Scenario: Студент находит справку из кабинета

* WHEN студент открывает `/settings?tab=home`
* THEN видна карточка «Справка и документация» со ссылками на
  docs/help.md, docs/assistant.md и docs/architecture.md
* WHEN студент открывает `/ai-assistant`
* THEN на странице есть ссылка на docs/assistant.md

#### Scenario: Ссылки не ведут в пустоту

* WHEN тест проверяет каждый путь из `DOCS_LINKS`
* THEN соответствующий файл существует в репозитории
