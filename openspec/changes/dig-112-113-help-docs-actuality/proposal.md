# Proposal: «Максимальная полнота» справки + актуализация README/wiki/docs (DIG-112/113)

## Зачем

Справка кабинета (/help + /guide) выросла инкрементально: экраны, добавленные
после DIG-73 (главная, успеваемость/рейтинг, уведомления, новости, профиль,
кабинет сотрудника /staff*), не получили ни раздела гайда «как пользоваться»,
ни статьи FAQ «частые вопросы». Студент (и сотрудник) не находит справку по
целым разделам меню, поиск по словоформам по ним молчит. Параллельно README
отстал от продукта: не упомянуты версия для слабовидящих (DIG-100), шеринг и
экспорт расписания (DIG-101), МСП, новости; в EN README пустовал раздел
«Mandatory core», а строка RU README «вход и БД подключаются в следующих
задачах» давно неверна. docs/wiki/ и docx-описание собрались 2026-11-18 и не
знают про DIG-99…103/120/124. Задача закрывает полноту справки и честность
документации без переписывания wiki целиком (список устаревшего — REPORT-112).

## Что

- **Гайд /guide** (`src/lib/help-content.ts`): +10 разделов RU и параллельных
  EN — dashboard, grades, notifications, news, profile, help-faq, staff,
  staff-requests, staff-appeals, staff-announcements (паттерн DIG-88: RU-канон,
  EN-тексты с теми же id/шагами/callout-видами).
- **FAQ /help** (`src/lib/faq-kb-catalog.ts`): новая категория `CABINET`
  («Кабинет и разделы» / EN «Cabinet screens») и 18 статей с кнопкой-глубинкой
  в каждый экран меню (dashboard, tasks, schedule, grades, finance, requests,
  notifications, deanery, feedback, events, msp, dpo, people, news, profile,
  settings, ai-assistant, staff; /mcp уже покрыт статьёй DIG-73). RU-тексты +
  EN-тексты в `FAQ_ARTICLES_EN_TEXT`; поиск по словоформам находит новые
  статьи без изменений движка (тот же стеммер `faqStems`).
- **Тест** (`tests/help-coverage.test.ts`, red-first): у каждого href меню
  (полное, таб-бар, «Ещё», staff) есть раздел гайда RU+EN и FAQ-статья с
  cta-глубинкой; RU/EN паритет обоих каталогов; EN-тексты без кириллицы;
  словоформы («уведомлений», «зачётка», «рейтинг группы»…) находят новые
  статьи. `tests/faq-catalog.test.ts`: категорий 7, а «только SCHOLARSHIPS»
  смягчено до «стипендии сверху, посторонние — только CABINET».
- **README.md / README.en.md**: упомянуты DIG-100 (версия для слабовидящих),
  DIG-101 («Поделиться» + экспорт MD/XLSX/PDF), МСП/новости/задачи/гайд;
  EN «Mandatory core» заполнен таблицей; устаревшая строка про «вход и БД в
  следующих задачах» исправлена; в таблицу быстрых ссылок добавлена
  `docs/wiki/` со ссылкой на отчёт устареваний.
- **docs/REPORT-112.md** (новый): пофайловый список того, что устарело в
  docs/wiki/ и docs/docx-описание/ (не переписываем — помечаем).
- **RAG плавающего ассистента** (`src/lib/floating-assistant-knowledge.ts`)
  подхватывает новые разделы и статьи автоматически — код не менялся.

## Non-goals

- Не переписываем docs/wiki/ и docx (только список расхождений в REPORT-112).
- Не меняем движок поиска, UI-компоненты справки, словари i18n.
- Не трогаем существующие RU-строки каталогов (байт-в-байт — закреплено
  тестами DIG-70/88).

## Риски и безопасность

Каталоги статичны и GET-only: IDOR невозможен по построению; серверных
поверхностей и секретов задача не добавляет. Плашка «Концепт для конкурса»
не затронута.
