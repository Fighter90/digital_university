# Delta: help-knowledge-base — статья справки на каждый экран меню

## MODIFIED Requirements

### Requirement: Категории плитками

Требование «Категории плитками» — обязательное (MUST): База знаний показывает
7 категорий: Учёба и сессия, Справки, Стипендии и выплаты, Общежитие,
Перевод и восстановление, IT и доступ, **Кабинет и разделы** (EN: Cabinet
screens). Каждая плитка показывает число статей; клик фильтрует список,
повторный клик снимает фильтр.

#### Scenario: Фильтр по новой категории

- **WHEN** пользователь кликает плитку «Кабинет и разделы»
- **THEN** в списке остаются только статьи категории `CABINET`
  (экраны кабинета и кабинет сотрудника)

## ADDED Requirements

### Requirement: Полнота справки — раздел гайда на каждый экран меню

Требование «Полнота справки» — обязательное (MUST): для каждого href из меню
кабинета (полное меню, таб-бар, «Ещё», разделы сотрудника /staff*; кроме
мета-разделов «Ещё» и самого /guide) в гайде /guide существует раздел с этим
href в RU-каталоге и параллельном EN-каталоге (тот же id, число шагов и
callout-ов совпадает, EN-тексты без кириллицы).

#### Scenario: экран из меню покрыт гайдом

- **WHEN** проверяется меню студента и сотрудника
  (`CABINET_SECTIONS ∪ TAB_SECTIONS ∪ MORE_SECTIONS ∪ STAFF_SECTIONS`)
- **THEN** для каждого не-мета href найдётся ровно соответствующий раздел
  гайда (RU и EN), например /dashboard, /grades, /notifications, /news,
  /profile, /help, /staff, /staff/requests, /staff/appeals,
  /staff/announcements

### Requirement: Полнота справки — статья FAQ на каждый экран меню

Требование «Статья FAQ на каждый экран» — обязательное (MUST): для каждого
не-мета href меню (кроме самой /help) существует статья базы знаний с
кнопкой-глубинкой (cta) в этот экран; каждой RU-статье соответствует
EN-текст в `FAQ_ARTICLES_EN_TEXT` (тот же id; вопрос/ответ непустые,
EN-тексты без кириллицы, у статей с RU-cta есть EN-подпись кнопки).

#### Scenario: экран покрыт статьёй FAQ

- **WHEN** проверяется меню студента и сотрудника
- **THEN** для каждого экрана найдётся статья категории «Кабинет и разделы»
  с cta в этот экран (для вложенных /staff/* достаточно статьи кабинета
  сотрудника с cta /staff; /mcp покрыт статьёй it-mcp-assistant)

#### Scenario: RU/EN паритет статей

- **WHEN** каталог статей локализуется (locale=en)
- **THEN** последовательность id статей совпадает с RU-каноном, каждая статья
  имеет EN-вопрос и EN-ответ, EN-тексты не содержат кириллицы

### Requirement: Поиск по словоформам находит новые статьи

Требование «Словоформы новых статей» — обязательное (MUST): статьи,
добавленные в категорию «Кабинет и разделы», находятся существующим поиском
(`searchFaqArticles`) по словоформам запроса без изменений движка.

#### Scenario: словоформы RU

- **WHEN** пользователь ищет «уведомлений», «зачётку», «рейтинг группы»,
  «стартапом», «объявления», «мероприятию»
- **THEN** находятся статьи cab-notifications, cab-grades, cab-msp,
  cab-staff, cab-events соответственно

#### Scenario: запросы EN

- **WHEN** пользователь ищет «notifications», «dashboard», «gradebook»,
  «staff queue» на EN
- **THEN** находятся соответствующие статьи EN-каталога
