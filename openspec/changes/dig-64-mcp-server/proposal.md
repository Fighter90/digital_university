# DIG-64 — MCP-сервер деканата: оценки/расписание в любом ассистенте (тренд PH)

## Why

Тренд Product Hunt 2026: продукты отдают свои данные ассистентам через MCP
(Kalender Sync → ChatGPT/Claude, Trainn MCP). У проекта уже есть вкладка
«Настройка MCP» (DIG-58), но она показывает только вымышленный каталог
внешних серверов — реального MCP-сервера у деканата нет. Для конкурса нужна
живая демонстрация тренда: ассистент (ChatGPT, Claude) подключается к
собственному демо-MCP-серверу деканата и отвечает на вопросы «моё расписание
на сегодня», «мои оценки», «мои непрочитанные».

## What Changes

- **Демо-MCP-сервер** на `POST /api/mcp` (Streamable HTTP, JSON-RPC 2.0):
  - `initialize` / `tools/list` / `tools/call` / `ping`;
  - три инструмента: `my_schedule_today`, `my_grades`, `my_unread`;
  - ответы — человекочитаемый текст на русском (для ассистентов).
- **Доступ по персональному демо-токену** (`Authorization: Bearer`):
  - токен выпускается владельцем сессии на вкладке «Настройка MCP»
    (кнопка «Создать токен»), в хранилище живёт только SHA-256-хэш + превью;
  - перевыпуск отзывает прежний токен;
  - lookup по хэшу возвращает только владельца (осознанное исключение из
    owner-scope порта — как `findCertificateByCode`, DIG-47), все данные
    читаются через скоупленный data-слой — IDOR исключён;
  - rate limit по IP (скользящее окно, как у входа/verify) — перебор токенов.
- **Вкладка «Настройка MCP»** (`/settings?tab=mcp`): новая карточка
  «MCP-сервер деканата» — URL сервера (абсолютный, из заголовков запроса),
  состояние персонального токена (создан/не создан, превью), кнопки
  «Создать токен» / «Перевыпустить», plaintext показывается один раз,
  инструкции подключения к ChatGPT и Claude (шаги + JSON-конфиг с
  `mcp-remote`).
- **Данные вымышленные**: инструменты читают демо-набор DIG-10/12
  (Анна/Илья), реальных вузов и ключей нет.

## Impact

- Спеки: новая capability `mcp` (сервер + токен) и delta `settings`
  (карточка сервера на вкладке).
- Lib: `src/lib/mcp-protocol.ts` (чистый JSON-RPC-диспетчер + каталог
  инструментов), `src/lib/mcp-format.ts` (форматирование ответов).
- Data: `StudentSettingsRow.mcpToken` (хэш/превью/createdAt/userId),
  порт `findStudentByMcpTokenHash`, модуль `src/server/data/mcp.ts`.
- Server: `src/server/mcp/` (генерация токена, инструменты, rate limit),
  роут `src/app/api/mcp/route.ts`, action `rotateMcpTokenAction`.
- Экран: `src/components/settings/mcp-deanery-server.tsx` + карточка на
  странице настроек.
- Prisma-схема НЕ меняется: data-слой прототипа работает на in-memory
  адаптере (как и все учебные данные).

## Non-goals

- Никаких реальных внешних сервисов и ключей; OAuth-сервер авторизации для
  MCP не строится (демо-токен вместо него).
- SSE-потоковая доставка (GET stream) не поддерживается — только JSON-ответы
  на POST (разрешено спецификацией Streamable HTTP).
- Ассистент кабинета (DIG-62) пока не вызывает MCP-сервер сам: инструменты
  адресованы внешним ассистентам (ChatGPT/Claude).
- Веб-сессии и MCP-токен независимы: выход из кабинета не отзывает токен
  (отзыв — перевыпуском на вкладке).
