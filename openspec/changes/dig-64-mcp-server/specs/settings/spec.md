# settings — delta (DIG-64)

## ADDED Requirements

### Requirement: Карточка «MCP-сервер деканата»

Требование «Карточка «MCP-сервер деканата»» — обязательное (MUST): Среди содержимого вкладки «Настройка MCP» есть карточка демо-MCP-сервера
деканата: абсолютный URL сервера (`/api/mcp`, из заголовков запроса) с
кнопкой копирования, состояние персонального токена (не создан — «Создать
токен»; создан — превью `demo-…` и «Перевыпустить токен»). Полный токен
показывается один раз сразу после выпуска/перевыпуска с кнопкой
копирования и предупреждением, что старый токен перестаёт действовать.
Карточка содержит пошаговые инструкции подключения к ChatGPT и Claude
(включая JSON-конфиг `mcp-remote`) и пометку, что данные вымышленные.

#### Scenario: Токен создаётся и показывается один раз

* WHEN студент на вкладке «Настройка MCP» нажимает «Создать токен»
* THEN показывается полный токен с кнопкой копирования
* AND после перезагрузки страницы виден только превью токена

#### Scenario: URL сервера виден

* WHEN студент открывает вкладку «Настройка MCP»
* THEN карточка показывает абсолютный URL, оканчивающийся на `/api/mcp`,
  и инструкции ChatGPT/Claude
