# DIG-99 — Пункт «MCP-сервер» в левом меню кабинета (/mcp)

## Why

Страница документации MCP `/mcp` (DIG-73) имеет заметный вход только в
мобильном меню «Ещё». В полном левом меню (десктоп ≥1024 и иконочный рельс
768–1023) пункта нет: фича MCP-сервера — одна из ключевых для конкурса, но
на десктопе студент её не видит. Нужен вход в боковом меню, видимый студенту.

## What Changes

- **`CABINET_SECTIONS`** (левое меню): пункт
  `{ href: '/mcp', label: 'Подключить ассистента (MCP)' }` — сразу после
  «AI-ассистент» (та же пара «ассистент + его подключение», что закреплена
  в «Ещё» с DIG-73), до разделителя перед «Профилем».
- Подпись — существующий ключ словаря `menu.mcp` (RU «Подключить ассистента
  (MCP)» не меняется, EN есть); иконка — уже существующая `Plug`
  (`nav-icons.tsx`); активное состояние — общая логика
  `resolveActiveSection` (подсветка на `/mcp`). Count-badge не нужен.
- Мобильное меню (таб-бар → «Ещё») уже содержит пункт с DIG-73 — задача
  закрепляет это тестом, изменений не требует.

## Impact

- Изменения: `src/components/shell/nav-items.ts` (одна строка),
  `tests/cabinet-shell.test.ts` (тест пункта).
- Серверных мутаций нет; новых env-переменных нет; IDOR-поверхностей нет.

## Non-goals

- Переименование пункта или RU-строк словаря.
- Новые иконки (Plug выбран DIG-73).
- Подпункты/вложенные страницы `/mcp/*`.
