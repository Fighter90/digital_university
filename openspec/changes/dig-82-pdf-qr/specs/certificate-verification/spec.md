# Delta-spec: certificate-verification — QR на мгновенных документах

## MODIFIED Requirements

### Requirement: Код проверки документа

Каждый цифровой документ с проверкой подлинности (справка по заявке
CERTIFICATE, мгновенная «Справка об обучении» CERT_ENROLLMENT,
«Выписка оценок» GRADES_EXTRACT) несёт уникальный код проверки —
32 символа base32 в группах по 4, и этот код СУЩЕСТВУЕТ в реестре
справок: страница `/verify/<код>` обязана открыть карточку документа.

- **WHEN** владелец скачивает PDF мгновенной справки или выписки
  (по заявке «ЗД-…» или мимо заявки — `/api/grades/transcript`)
  **THEN** документ печатает код проверки из записи реестра и
  сканируемый QR со ссылкой `${origin}/verify/<код>`; запись создаётся
  при первом скачивании (код из криптографического ГСЧ, 160 бит) и
  переиспользуется при повторных (QR остаётся действительным).
- **WHEN** выписка скачивается мимо заявки
  **THEN** реестр ключуется стабильным синтетическим ключом на пару
  (студент, тип документа) — один код на студента и тип документа.
- **WHEN** срок действия мгновенного документа истекает (30 дней,
  как напечатано на PDF справки)
  **THEN** страница проверки отвечает «Документ не найден» (единый
  ответ с неверным/чужим кодом, без «оракула» существования).

### Requirement: Блок «Проверка подлинности» в PDF мгновенных документов

PDF мгновенной справки и выписки содержит блок проверки со
сканируемым QR; обещание «QR-код появится» и пунктирная рамка-заглушка
запрещены.

- **WHEN** PDF собирается при равных входах
  **THEN** вывод байт-в-байт детерминирован; QR нарисован
  модулями-квадратами (энкодер `src/lib/pdf/qr.ts`, сервер, без внешних
  API и клиентских библиотек), число модульных квадратов в контенте
  равно числу тёмных модулей матрицы (проверяется парсером).
- **WHEN** QR «сканируют» декодером (BCH + Рида–Соломона + byte-mode)
  **THEN** из матрицы восстанавливается ровно verify-URL, напечатанный
  в том же блоке текстом («Проверить по ссылке или QR-коду: …»).
- **WHEN** блок проверки попадает к низу страницы (плотная выписка)
  **THEN** блок целиком переносится на новую страницу: QR не пересекает
  нижнее поле; строки блока переносятся по ширине, чтобы не заходить
  под квадрат QR (96 pt ≈ 34 мм).

### Requirement: Скоуп выдачи кода мгновенного документа

- **WHEN** контекст не студент или `studentId` входа не совпадает с
  контекстом
  **THEN** `getOrCreateDocumentVerification` отвечает null и пишет отказ
  в аудит (`ROLE_MISMATCH` / `OWNERSHIP_DENIED` через `denyAccess`);
  чужой номер заявки отвечает тем же единым 404 роута (IDOR исключён).
