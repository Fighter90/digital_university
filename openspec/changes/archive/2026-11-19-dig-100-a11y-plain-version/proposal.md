# Proposal: «Версия для слабовидящих» — plain-режим без декоративных стилей (DIG-100)

## Зачем

Отдельный режим доступности входом по ссылке: полоска-ссылка НАД шапкой
(кабинет + лендинг) и ссылка со значком Eye в футере. В отличие от тумблеров
DIG-86 («Крупный текст и без эффектов»), plain-версия — радикальная: белый
фон, чёрный текст, синие подчёркнутые ссылки, базовый шрифт с засечками
≥20px, линейная колонка вместо сеток, без градиентов/теней/анимаций/фонов —
как классическая «версия для слабовидящих» госсайтов. Обратная ссылка
«Обычная версия» — в тех же местах.

## Что

- Cookie `du-a11y-version` (`plain` | `off`) — паттерн du-a11y (DIG-86) и
  du-locale (DIG-69): без data-слоя, срок жизни год.
- Server action `toggleA11yVersion` (owner-scoped: `requireDataCtx` по живой
  сессии — анонимный посетитель выпадает на /login, IDOR невозможен).
  Поле `next` — необязательный внутренний путь возврата после входа
  (строгий whitelist «/…», open redirect исключён).
- Root layout: cookie=plain → класс `a11y-plain` на `<html>` server-side,
  до первой отрисовки, на всех страницах.
- Компонент `A11yVersionLink` (форма с server action, работает без JS):
  вариант strip — полоска над шапкой Shell кабинета и над шапкой лендинга;
  вариант footer — ссылка со значком Eye в футере лендинга и Shell.
- Словарь `a11y.version.*` парой RU/EN: «Версия для слабовидящих» /
  «Accessibility version», «Обычная версия» / «Standard version».
- globals.css: слой в самом конце файла — переопределения под `.a11y-plain`
  (в т.ч. media-блок 360px). Plain перекрывает тему/размер шрифта (DIG-44),
  режимы DIG-86 и prefers-reduced-motion — включает их поведение.

## Non-goals

- Не трогаем существующие RU-тексты и экран «Настройки → Доступность» (DIG-86) —
  режимы сосуществуют, plain лишь приоритетнее.
- Не добавляем поле в строку настроек (cookie достаточно, паттерн du-locale).
- Не меняем `scripts/swarm/`, заголовки безопасности, rate-limit входа.
- Не переводим DEMO-контент (правило i18n DIG-69).
