# DIG-62 — «AI-гид по кабинету»: ассистент проводит студента по экранам

## Why

Тренд Product Hunt: AI-агент ведёт пользователя по продукту (Aven App Agent,
Trainn). В кабинете уже есть AI-ассистент как раздел-заглушка (DIG-59) и
плавающая кнопка (DIG-14), но никто не знакомит нового студента с кабинетом:
первый вход — пустой дашборд без подсказок. Для конкурса нужен наглядный
«AI-гид»: при первом входе он предлагает экскурсию по кабинету и отвечает
на базовые сценарии ссылкой-кнопкой на нужный экран.

## What Changes

- **Приветствие на первом входе**: панель AI-гида (компонент `AiGuide`,
  монтируется в `Shell`) раскрывается у студента один раз — на первом входе
  в кабинет (экран `/dashboard`) — и предлагает экскурсию
  «расписание → оценки → заявки → справки».
- **Экскурсия**: 4 шага с кнопкой-ссылкой «Открыть экран»
  (`/schedule` → `/grades` → `/requests` → `/services`); прогресс «шаг N из 4».
- **Сценарии-подсказки**: чипы «Где мои справки?» и «Как записаться
  на пересдачу?» + свободный ввод вопроса; ответ — текст и кнопка-ссылка
  на нужный экран (`/services`, `/grades/session`). Неизвестный вопрос —
  честный ответ «такого сценария в демо нет».
- **Отключаемость**: показ и любой способ закрыть/пройти гида записывают
  флаг `ai-guide:seen` в localStorage — повторные входы гида не открывают;
  гид доступен вручную через пилюлю «AI-гид» в любой момент.
- **Роль**: гид показывается только студенту (`role === 'STUDENT'`);
  сотруднику кабинета гид не мешает.

## Impact

- Спека: новая capability `ai-guide` (delta — ADDED requirements).
- Чистый модуль: `src/lib/ai-guide.ts` (шаги экскурсии, сценарии с
  ключевыми словами, `matchAiGuideScenario`, localStorage-хелперы).
- Клиентский компонент: `src/components/shell/ai-guide.tsx` (пилюля +
  панель приветствия/экскурсии/ответа), монтирование в `Shell`.
- Тесты: `tests/ai-guide.test.tsx` (unit, jsdom), `e2e/ai-guide.spec.ts`
  (первый вход, отключаемость, сценарии ведут на экраны, 360/1440).

## Non-goals

- Никакого настоящего LLM/сети: ответы — детерминированный матчинг по
  ключевым словам (конкурсный прототип, вымышленные данные).
- Гид не пишет в БД и не создаёт заявок — только навигация по существующим
  экранам; серверных экшенов у фичи нет (IDOR-поверхность отсутствует).
- Отдельный экран `/ai-assistant` (диалог с ассистентом) — вне задачи.
