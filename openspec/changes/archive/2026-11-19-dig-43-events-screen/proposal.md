# DIG-43 — Экран «Мероприятия»: события вуза и запись

## Зачем

Студент видит жизнь вуза за пределами пар: открытые лекции, хакатоны,
карьерные и культурные события. В аудированном ЛК записи на мероприятия
нет вовсе — афиша живёт в постах и чатах. В кабинете появляется раздел
«Мероприятия» (/events): лента карточек с фильтрами и записью в один
клик, повторное нажатие отменяет запись. Прототип конкурсный: все
события, места и работодатели вымышленные.

Экран строится по свежему эталону DIG-68 «МСП» (/msp): общий каталог по
публичному slug, owner-scoped мутации студента, аудит отказов, слои
данных добавляются В КОНЕЦ секций (merge-безопасность).

## Что сделано

- **Data-слой** (`EventRow`, `EventRegistrationRow`; UNIQUE пара
  мероприятие+студент): `listEventsByRange`, `listEventRegistrationsByStudent`,
  `toggleEventRegistration` (запись → отмена; при заполненной вместимости
  запись не создаётся), `listEventAttendeeCount`. «Осталось N мест» =
  capacity − занято.
- **Фасад** `server/data/events.ts`: `getEventsPage` (фильтры
  week/faculty/career/online через ?filter=, сортировка по дате старта),
  `openEventView` (карточка по slug), `toggleEventRegistrationForStudent`
  (сотруднику — ROLE_MISMATCH, несуществующее мероприятие — NOT_FOUND,
  аудит как в msp.ts).
- **Экраны**: /events — лента + чипы фильтров + кнопка записи;
  /events/[slug] — описание, дата/время/место (или ссылка трансляции),
  вместимость/занято, запись, заглушка «Друзья не пойдут», единый
  контрактный 404. Скелетон — в route-group (feed).
- **Обложки-заглушки**: детерминированный градиент по FNV-хэшу названия
  + иконка Lucide по типу — без внешних картинок и random.
- **Меню**: MORE_SECTIONS += «Мероприятия» (/events), иконка
  CalendarHeart (Sparkles занят AI-ассистентом).
- **Связь с расписанием**: в прототипе записанное мероприятие НЕ
  добавляется в /schedule (пометлено комментариями в actions и на
  карточке) — синхронизация «запись → слот расписания» за пределами
  этого change.
- **Сид**: 8 вымышленных событий (+1..+30 дней, 3 онлайн), записи
  демо-студентов, экскурсия 5/5 («Мест нет»), у Анны два чипа «Записан».

## Non-goals

- Список друзей на мероприятии («Друзья не пойдут») — заглушка, не
  наполняется.
- Синхронизация записей с /schedule и ICS-подпиской.
- Создание/редактирование мероприятий студентами или сотрудниками.
