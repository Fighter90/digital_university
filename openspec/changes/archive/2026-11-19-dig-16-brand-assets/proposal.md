# DIG-16 — Логотип и иллюстрации (Higgsfield): подключить в приложение

## Зачем

У прототипа нет визуального бренда: логотип — текстовая заглушка «ЦД», пустые
состояния — иконки lucide, favicon — дефолтный из шаблона Next, OG-превью и
PWA-иконки отсутствуют. Для конкурса (критерий «ИИ-инструменты для дизайна»)
нужен собственный визуальный слой, сгенерированный ИИ, с сохранёнными промптами.

## Что делаем

1. **Логотип-знак** «книга + шапочка в коралловом скруглённом квадрате»:
   SVG-версия (`public/brand/logo.svg` + компонент `BrandLogo`), favicon
   (`src/app/icon.png`), apple-touch-icon (`src/app/apple-icon.png`), PWA
   192/512 (`public/icons/`) + `src/app/manifest.ts`. Заменяет «ЦД» в Shell.
2. **Иллюстрации пустых состояний** (WebP ≤ 80 КБ, через `next/image`,
   декоративные `alt=""` + `aria-hidden`): «Нет пар сегодня», «Заявок пока
   нет», «Нет уведомлений», «Что-то пошло не так» (404), «Справка готова»,
   hero входа. Компонент `Illustration` + проп `illustration` у
   `EmptyState`/`ErrorState`.
3. **OG-превью 1200×630** (`public/og.jpg`) в metadata layout + Twitter card;
   **обложка PDF-описания** (`public/brand/pdf-cover.jpg`).
4. **Документирование**: `docs/ai-log/assets.md` (инструменты, промпты,
   исходники в `docs/ai-log/assets-src/`), лицензия — в
   `THIRD_PARTY_LICENSES.md`.

## Ограничение

Кредиты Higgsfield (free-план) закончились в ходе задачи: проба логотипа
сгенерирована в Higgsfield (`z_image`), финальные иллюстрации — та же модель
Recraft V4.1 (Flash) через встроенный генератор сессии. Промпты и исходники
сохранены полностью; лимит ≤ 80 КБ соблюдён.

## Non-goals

- Не менять вёрстку экрана входа DIG-18 (hero-иллюстрация добавлена
  дополнительным блоком, «парящие» карточки сохранены).
- Не трогать PDF-генерацию справок (DIG-47) и scripts/swarm/.
- Тёмная тема иллюстраций не требуется (иллюстрации декоративные).
