# Delta: cabinet-i18n — EN-перевод ключевых страниц

## ADDED Requirements

### Requirement: Ключевые страницы кабинета рендерят контент по локали

Требование «Ключевые страницы кабинета рендерят контент по локали» — обязательное (MUST): Переключение локали (`du-locale`) переводит основной контент ключевых страниц:
сводка успеваемости `/grades`, зачётная книжка `/grades/gradebook`, выписка из
зачётки (PDF `/api/grades/transcript`) и карточка заявки `/requests/[номер]`.

#### Scenario: EN-сводка успеваемости без русских строк контента

- **WHEN** студент с локалью `en` открывает `/grades`
- **THEN** пилюли семестров, блок среднего балла (включая дельту
  «vs Spring 25/26»), кредиты, рейтинг группы, светофор, карточки дисциплин
  (словесные пороги, бейджи допуска), долги и пустые/ошибочные состояния
  отрендерены на английском
- **AND** демо-контент (ФИО, названия дисциплин) остаётся на русском

#### Scenario: RU-рендер байт-в-байт прежний

- **WHEN** локаль `ru` (дефолт, в т.ч. без cookie)
- **THEN** все строки экранов совпадают с прежними байт-в-байт
  (юнит-снимки и e2e не меняются)

### Requirement: Выписка PDF собирается по локали сессии

Требование «Выписка PDF собирается по локали сессии» — обязательное (MUST):

#### Scenario: EN-выписка

- **WHEN** студент с локалью `en` скачивает `/api/grades/transcript`
- **THEN** заголовок, шапка студента, колонки таблицы, итоги семестров,
  блок проверки подлинности — на английском (глифы латиницы покрыты
  векторным шрифтом)

### Requirement: Карточка заявки локализует статусы и подписи

Требование «Карточка заявки локализует статусы и подписи» — обязательное (MUST):

#### Scenario: EN-карточка заявки «ЗД-…»

- **WHEN** студент с локалью `en` открывает карточку канонической заявки
- **THEN** статус-пилюля, «подана», «Готовность до», «Ведёт», алерты
  доработки/отказа, блок документа, параметры и вложения мастера, заголовки
  «Параметры заявки»/«Вложения»/«История заявки» — на английском;
  таймлайн пересобирает подписи переходов по словарю

### Requirement: Хелперы presentation-слоя локале-параметричны

Требование «Хелперы presentation-слоя локале-параметричны» — обязательное (MUST): Существующие чистые хелперы принимают необязательный хвостовой параметр
`locale = 'ru'`; вызовы без параметра и RU-тесты остаются валидными.

#### Scenario: EN-подписи хелперов

- **WHEN** хелпер вызван с `'en'`
- **THEN** подпись строится по словарю EN (`semesterShortLabel` →
  «Fall 26/27», `bestPercentLabel(1, 1)` → «You are the only student in the
  group», `trafficLight` → «All good», выписка → «Academic transcript»)
