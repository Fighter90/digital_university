# Delta: landing-screen

## ADDED Requirements

### Requirement: Hero лендинга на «/»

Требование «Hero лендинга на «/»» — обязательное (MUST): Корень «/» — публичный лендинг цифрового деканата, доступный без
авторизации. Hero содержит строку бренда «Цифровой деканат», заголовок
«Всё университетское — в одном окне», подзаголовок с перечислением
возможностей и две CTA: «Войти» и «Демо-доступ». Обе CTA — ссылки на
`/login`. H1 содержит имя продукта (контракт e2e smoke DIG-6 сохраняется).
Плашка «Концепт для конкурса» наследуется из корневого layout.

#### Scenario: Лендинг открывается без авторизации

- **WHEN** анонимный посетитель открывает «/»
- **THEN** рендерится hero: бренд «Цифровой деканат», слоган
  «Всё университетское — в одном окне», подзаголовок и обе CTA

#### Scenario: CTA ведут на вход

- **WHEN** посетитель нажимает «Войти» или «Демо-доступ»
- **THEN** происходит переход на `/login` (форма входа)

### Requirement: Секции преимуществ

Требование «Секции преимуществ» — обязательное (MUST): Лендинг показывает 5 карточек преимуществ с иконкой и коротким
описанием: расписание, оценки, заявки, справки с QR, AI-ассистент.
После карточек — финальный CTA-блок с ссылкой на `/login` и футер.

#### Scenario: Пять возможностей

- **WHEN** посетитель прокручивает лендинг
- **THEN** видны карточки «Расписание», «Оценки», «Заявки»,
  «Справки с QR», «AI-ассистент», у каждой — иконка и описание

### Requirement: Анимации появления и hover-эффекты

Требование «Анимации появления и hover-эффекты» — обязательное (MUST): Секции и карточки плавно появляются при попадании в вьюпорт
(IntersectionObserver, каскадные задержки, без внешних зависимостей);
карточки преимуществ при наведении приподнимаются с тенью hover.
При `prefers-reduced-motion` или отсутствии IntersectionObserver
контент отображается без анимации и никогда не остаётся скрытым.

#### Scenario: Появление при прокрутке

- **WHEN** блок с `data-reveal` попадает во вьюпорт
- **THEN** блок получает класс видимости и остаётся видимым

#### Scenario: Деградация без IntersectionObserver

- **WHEN** IntersectionObserver недоступен
- **THEN** содержимое `Reveal` отображается сразу, скрытого контента нет
