# DIG-99 — delta: mcp-docs — пункт «MCP-сервер» в меню кабинета

## MODIFIED Requirements

### Requirement: Вход из меню и справки

Требование «Вход из меню и справки (DIG-73 → DIG-99)» — обязательное (MUST): Пункт «Подключить ассистента (MCP)» присутствует в левом меню кабинета
(`CABINET_SECTIONS`: полный список ≥1024 и иконочный рельс 768–1023) рядом
с «AI-ассистент», в мобильном меню «Ещё» (`MORE_SECTIONS`) — с иконкой Plug,
без count-badge — и ведёт на `/mcp`; `/mcp` подсвечивает пункт меню (и
вкладку «Ещё» на мобильном). Раздел «Подключить внешнего AI-ассистента
(MCP)» присутствует в справке `/guide`; FAQ-статья про подключение
ассистента присутствует в `/help`. Интерфейсные подписи пункта меню и
заголовка локализованы RU/EN (ключ `menu.mcp` не переименовывается).

#### Scenario: Студент видит пункт в левом меню

* WHEN студент открывает кабинет на десктопе (левое меню ≥768 px)
* THEN пункт «Подключить ассистента (MCP)» виден в меню сразу после
  «AI-ассистент» и ведёт на `/mcp`

#### Scenario: Активное состояние пункта

* WHEN студент находится на `/mcp`
* THEN пункт «Подключить ассистента (MCP)» в левом меню подсвечен
  (`aria-current="page"`), другие пункты — нет; `/mcp-extra` подсветку
  не вызывает

#### Scenario: Мобильный вход сохраняется

* WHEN студент на мобильном (<768 px) открывает «Ещё»
* THEN пункт «Подключить ассистента (MCP)» присутствует, а открытый `/mcp`
  подсвечивает вкладку «Ещё»
