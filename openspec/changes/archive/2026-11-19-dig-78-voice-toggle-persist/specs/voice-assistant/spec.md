# DIG-78 — delta: voice-assistant — переключатель озвучки сохраняет состояние

## ADDED Requirements

### Requirement: Переключатель «Озвучка и голосовой ввод» отражает сохранённое состояние

Требование «Переключатель «Озвучка и голосовой ввод» отражает сохранённое состояние» — обязательное (MUST): Вкладка «Вид» (/settings) рендерит карточку «Озвучка и голосовой ввод» с
переключателем (role=switch, aria-label «Озвучка и голосовой ввод»). Состояние
переключателя синхронизировано с персистентной строкой настроек студента
(StudentSettings.voiceAssistant), а не с локальным оптимистичным состоянием.

#### Scenario: Включение переживает перезагрузку

- **WHEN** студент включает переключатель «Озвучка и голосовой ввод»
- **AND** server action `saveVoiceAssistantAction(true)` завершается успешно
  (строка StudentSettings перезаписана, voiceAssistant=true)
- **AND** студент перезагружает страницу /settings?tab=appearance
- **THEN** переключатель рендерится с `aria-checked="true"`
- **AND** голосовые функции кабинета («Прослушать день», микрофон AI-гида)
  снова доступны.

#### Scenario: aria-checked не опережает запись

- **WHEN** студент переключает тумблер
- **THEN** `aria-checked` меняется не раньше успешного завершения
  `saveVoiceAssistantAction` (пока action в полёте — состояние предыдущее,
  статусная строка показывает «Сохранение…»).

#### Scenario: Отказ сохранения откатывает переключатель

- **WHEN** `saveVoiceAssistantAction` возвращает false (не студент, сбой слоя
  данных, невалидный аргумент)
- **THEN** переключатель остаётся в исходном (сохранённом) состоянии
- **AND** статусная строка сообщает об ошибке сохранения; значение в БД не
  изменилось.
