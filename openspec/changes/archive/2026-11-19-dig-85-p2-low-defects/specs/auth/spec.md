# DIG-85 — delta: auth — вход после выхода

## ADDED Requirements
### Requirement: Вход после выхода

Требование «Вход после выхода» — обязательное (MUST):

#### Scenario: Вход с /login?signedOut=1 завершается ошибкой
- **WHEN** вход с /login?signedOut=1 завершается ошибкой
- **THEN** параметр signedOut убирается из адресной строки (без перезагрузки страницы) и устаревший статус «Вы вышли из кабинета» скрывается — вместе с ошибкой не показывается ни одного противоречащего сообщения.
