# DIG-85 — delta: voice-assistant — запасное поведение «Прослушать день»

## ADDED Requirements
### Requirement: Запасное поведение «Прослушать день»

Требование «Запасное поведение «Прослушать день»» — обязательное (MUST):

#### Scenario: Браузер содержит speechSynthesis
- **WHEN** браузер содержит speechSynthesis, но голосовые движки недоступны (озвучка не стартовала) **THEN** в течение ~1.2 с появляется запасное сообщение role="status" «Голосовой движок недоступен…», кнопка возвращается в исходное состояние; молчаливое «ничего не произошло» запрещено.

#### Scenario: SpeechSynthesisUtterance бросает исключение
- **WHEN** SpeechSynthesisUtterance бросает исключение
- **THEN** показывается то же запасное сообщение.
