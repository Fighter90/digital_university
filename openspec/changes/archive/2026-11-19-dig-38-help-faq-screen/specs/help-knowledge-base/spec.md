# Delta: help-knowledge-base

## ADDED Requirements

### Requirement: Поиск по базе знаний находит статьи по словоформам

Требование «Поиск по базе знаний находит статьи по словоформам» — обязательное (MUST): Запрос пользователя сопоставляется с заголовком и текстом статей с
учётом русских словоформ: поисковые токены приводятся к стему
(снежный ком, словарь суффиксов как у `to_tsvector('russian')`), токен
запроса совпадает с токеном статьи, если стемы равны или короткий стем
является префиксом длинного (стипенди ⊂ стипендиальн). Стоп-слова
(«как», «получить» и т.п.) не участвуют; несколько токенов соединяются
AND; совпадение в заголовке ранжируется выше совпадения в тексте.

#### Scenario: Запрос «стипендия» возвращает статьи про стипендии

- **WHEN** пользователь вводит в поле «Найдите ответ» запрос «стипендия»
- **THEN** в результатах есть ≥3 статьи категории «Стипендии и выплаты»
  («Когда приходит стипендия?», «Как получить повышенную стипендию?», …)

#### Scenario: Словоформы находят те же статьи

- **WHEN** пользователь вводит «стипендиальный» (или «стипендии»,
  «стипендию», «повышенная стипендия»)
- **THEN** результаты включают статьи про стипендии; форма
  «справедлив» не находит статьи раздела «Справки»

#### Scenario: Пустой и мусорный запрос

- **WHEN** запрос пустой или не совпадает ни с одной статьёй
- **THEN** показывается состояние «Ничего не нашлось» (см. ниже), а не
  пустой список без подсказок

### Requirement: Категории плитками

Требование «Категории плитками» — обязательное (MUST): База знаний показывает ровно 6 категорий: Учёба и сессия, Справки,
Стипендии и выплаты, Общежитие, Перевод и восстановление, IT и доступ.
Каждая плитка показывает число статей; клик фильтрует список, повторный
клик снимает фильтр.

#### Scenario: Фильтр по категории

- **WHEN** пользователь кликает плитку «Общежитие»
- **THEN** в списке остаются только статьи категории «Общежитие»

#### Scenario: Фильтр скрывает результаты живого поиска

- **WHEN** поиск нашёл статьи, но включённый фильтр категории скрывает их все
- **THEN** показывается записка «В категории … по запросу … статей нет»
  с кнопкой сброса фильтра, а не состояние «Ничего не нашлось»

### Requirement: Статья с обратной связью и сервисной кнопкой

Требование «Статья с обратной связью и сервисной кнопкой» — обязательное (MUST): Статья `/help/<slug>` показывает вопрос, ответ, блок «Полезно? Да / Нет»,
связанные статьи и кнопку сервиса, если ответ ведёт к заявке
(например «Заказать справку» → `/requests?order=cert-enrollment`).
Неизвестный slug — 404.

#### Scenario: Фидбек статьи

- **WHEN** пользователь нажимает «Да» (или «Нет»)
- **THEN** кнопки заменяются благодарностью, повторный выбор возможен

#### Scenario: Кнопка сервиса

- **WHEN** пользователь открывает статью «Какие справки можно заказать онлайн?»
- **THEN** в статье есть кнопка «Заказать справку» со ссылкой
  `/requests?order=cert-enrollment`

### Requirement: Ноль результатов — не тупик

Требование «Ноль результатов — не тупик» — обязательное (MUST): Когда поиск не находит ни одной статьи, экран всегда предлагает два
следующих действия: «Спросить AI-ассистента» и «Написать в деканат»,
текст запроса переносится в параметр `q` обеих ссылок — и целевые экраны
его подхватывают: у AI-ассистента запрос сеется первым вопросом чата,
в деканате запрос предзаполняет черновик нового обращения.

#### Scenario: Два следующих действия при нуле результатов

- **WHEN** пользователь вводит запрос без совпадений (например «фыгвпркст»)
- **THEN** виден блок «Ничего не нашлось» со ссылками
  `/ai-assistant?q=фыгвпркст` и `/deanery?q=фыгвпркст`

#### Scenario: Перенос запроса в целевые экраны

- **WHEN** пользователь переходит по «Написать в деканат»
- **THEN** композер нового обращения открыт с текстом запроса в поле
  описания; по «Спросить AI-ассистента» запрос сеется первым вопросом чата

### Requirement: Навигация до базы знаний

Требование «Навигация до базы знаний» — обязательное (MUST): Раздел «Вопросы и ответы» (`/help`) присутствует в боковом меню
кабинета (десктоп) и в списке «Ещё» (мобайл); активное состояние
подсвечивается как у остальных разделов.

#### Scenario: Пункт меню

- **WHEN** пользователь открывает кабинет
- **THEN** в меню есть ссылка «Вопросы и ответы» → `/help`
