# DIG-58 — «Настройка MCP»: пункт в настройках + расширенный раздел справки

## Why

Цифровой ассистент кабинета (DIG-46) задуман расширяемым через MCP
(Model Context Protocol) — по образцу публичных установочных страниц
внешних MCP-серверов (например, Product Hunt MCP, producthunt.com/mcp/install).
Сейчас в настройках нет пункта «Настройка MCP»: студент не видит, какие
MCP-серверы доступны ассистенту, в каком они статусе и как их подключить.
Для конкурса нужна наглядная демонстрация интеграционной модели на
вымышленных демо-данных (реальных ключей нет).

## What Changes

- **Вкладка «Настройка MCP»** на экране `/settings` (пятая вкладка, `?tab=mcp`):
  - список MCP-серверов цифрового ассистента: имя, что даёт, статус
    («Подключён» / «Не подключён»), кнопка «Подключить» с инструкцией —
    deep-ссылка и демо-токен (кнопка «Скопировать»);
  - карточки-примеры: Product Hunt (тренды), Календарь, Деканат-API —
    что даёт каждый сервер;
  - расширенный раздел справки: как работает MCP, безопасность токенов,
    пошаговая установка, частые ошибки.
- **Демо-хранилище**: состояние подключения каждого сервера сохраняется
  в настройках студента (`StudentSettingsRow.mcpConnections`), как и
  остальные настройки — переживает перезагрузку страницы.
- **Данные вымышленные**: три демо-сервера с фиктивными токенами вида
  `demo-*-mcp-…` и фиктивной deep-ссылкой (`unidemo://…`); на экране есть
  пометка, что ключей и доступа к реальным сервисам нет (конкурсный прототип).

## Impact

- Спека: `settings` (delta — новая вкладка + требование MCP-списка).
- Модель настроек: `StudentSettingsRow.mcpConnections` (список
  `{ id, connected }` по каталогу), нормализация старых строк без поля.
- Data-слой: `updateOwnMcpConnection` (только свой ctx, whitelist id —
  IDOR исключён); server action `setMcpServerConnectionAction`.
- Экран: `src/components/settings/mcp-settings.tsx` (client — статус,
  инструкция, сохранение) + статические карточки и справка на странице.

## Non-goals

- Никаких реальных MCP-соединений, ключей и внешних запросов — прототип.
- Ассистент (DIG-46) пока не вызывает подключённые серверы: это экран
  настроек и справки, не рантайм ассистента.
- Отдельная таблица/модель БД под подключения не вводится (демо-хранилище
  настроек уже персистентно в рамках прототипа).
