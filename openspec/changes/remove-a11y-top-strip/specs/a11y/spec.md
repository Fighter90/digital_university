# Delta: accessibility (a11y) — точка входа в plain-режим

## MODIFIED Requirements

### Requirement: Plain-версия для слабовидящих по ссылке

Кабинет и лендинг предоставляют ссылку включения plain-версии в ФУТЕРЕ
(со значком Eye): форма с server action `toggleA11yVersion`
(`version=plain`, `next` — текущий путь), работает без JavaScript.
Полоска-ссылка над шапкой убрана (по решению владельца); в plain-режиме
обратная ссылка «Обычная версия» / «Standard version» — в том же футере.

#### Scenario: Включение plain-версии по ссылке в футере

* WHEN владелец сессии нажимает ссылку «Версия для слабовидящих» в футере
  (кабинета или лендинга)
* THEN ставится cookie `du-a11y-version=plain` и на следующей отрисовке
  `<html>` получает класс `a11y-plain`

#### Scenario: Полоски над шапкой нет

* WHEN открывается любая страница кабинета или лендинга
* THEN элемент `a11y-version-strip` отсутствует в DOM, первая видимая
  зона страницы — шапка

#### Scenario: Обратный выход из plain-версии

* WHEN plain-версия включена и владелец нажимает «Обычная версия» в футере
* THEN ставится cookie `du-a11y-version=off` и класс `a11y-plain`
  снимается
