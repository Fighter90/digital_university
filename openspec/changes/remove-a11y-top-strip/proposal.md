# Proposal: remove-a11y-top-strip

## Зачем
По решению владельца (20.11, при финальной полировке к дедлайну): полоска
«Версия для слабовидящих» над шапкой визуально утяжеляет верх страниц
(лендинг и кабинет) и дублирует функцию футер-ссылки. Вход в plain-режим
остаётся — по ссылке со значком Eye в футере (и обратная ссылка там же).

## Что меняется
- Убирается рендер `A11yVersionLink variant="strip"` из `Shell` (кабинет)
  и `LandingContent` (лендинг).
- Компонент `version-link.tsx` остаётся без изменений (вариант `strip`
  сохранён в компоненте, но нигде не используется).
- Обновляются тесты: `tests/a11y-version-places.test.tsx` (полоски нет,
  футер работает RU/EN/plain), e2e `zz-dig-106-107-regress.spec.ts`
  (вход в plain через футер-ссылку).

## Non-goals
- Plain-режим, CSS-слой, cookie-контракт, action `toggleA11yVersion` — не меняются.
- Футер-ссылка и её поведение — не меняются.

## Источник
Прямая просьба владельца в сессии супервизора (20.11); bриф-критерий
«Доступность» не страдает — вход в plain-версию сохранён.
