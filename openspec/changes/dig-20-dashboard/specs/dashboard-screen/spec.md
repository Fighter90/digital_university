# Delta: dashboard-screen (DIG-20)

## ADDED Requirements

### Requirement: Главная собирается одним серверным запросом-агрегатом

Страница `/dashboard` ДОЛЖНА получать данные через один агрегат
`getDashboard(db, ctx)`, который читает все источники параллельно
(`Promise.all` над изолированным портом данных) без водопада запросов.
Сбой отдельного источника ДОЛЖЕН осесть в `Section<T>` и НЕ ронять страницу:
блок с ошибкой отрисовывает собственное состояние ошибки (`role="alert"`),
остальные блоки остаются работоспособными.

#### Scenario: агрегат без водопада

- **WHEN** студент открывает /dashboard
- **THEN** страница делает один вызов агрегата; порт данных читается
  параллельно (profile, schedule, exams, grades, requests).

#### Scenario: сбой одного источника

- **WHEN** один из источников агрегата выбрасывает ошибку
- **THEN** соответствующий блок показывает своё состояние ошибки,
  остальные блоки отрисованы, страница не падает.

### Requirement: Hero «Ваша неделя»

Главная ДОЛЖНА начинаться с единственного тёмного блока-героя «Ваша неделя ·
<день недели, дата>» с коралловым свечением: приветствие по имени (по времени
суток), строка-резюме, собранная детерминированно из данных (число пар,
переносов, отмен, дней до пересдачи; без LLM), и 4 плитки-ссылки: средний
балл с дельтой (→ /grades), кредиты X/240 (→ /profile), долги (→ /schedule),
заявки в работе (→ /requests). На 360 px плитки ДОЛЖНЫ идти сеткой 2×2.

#### Scenario: сводка из данных

- **WHEN** в группе сегодня 4 пары, одна перенесена, одна отменена и через
  7 дней пересдача
- **THEN** строка-резюме: «Сегодня 4 пары, одна перенесена, одна отменена.
  До пересдачи 7 дней.»

#### Scenario: плитки ведут в свои разделы

- **WHEN** пользователь нажимает плитку «Средний балл»
- **THEN** открывается /grades; аналогично кредиты → /profile, долги →
  /schedule, заявки → /requests.

### Requirement: Таймлайн «Сегодня»

Блок «Сегодня» ДОЛЖЕН показывать пары группы за текущий день (время, пилюля
типа занятия, дисциплина, аудитория, преподаватель). Пара со сменой аудитории
ДОЛЖНА быть выделена пунктиром и жёлтым фоном с подписью «Перенос: ауд. X →
Y»; отменённая — зачёркнута; пара в аудитории «Онлайн» — со ссылкой «Онлайн».
Если пар нет — иллюстрация «Нет пар сегодня» и ближайший учебный день.

#### Scenario: перенесённая пара

- **WHEN** сегодняшняя пара имеет статус ROOM_CHANGED (previousRoom 214,
  room 305)
- **THEN** карточка пары с пунктирной границей, жёлтым фоном и текстом
  «Перенос: ауд. 214 → 305».

#### Scenario: пустой день

- **WHEN** на текущую дату пар нет
- **THEN** показан EmptyState «Нет пар сегодня» с ближайшим учебным днём
  (дата и число пар) и ссылкой в расписание.

### Requirement: Ближайшие дедлайны

Блок ДОЛЖЕН показывать до трёх будущих сессий группы (зачёт/экзамен/
пересдача): дата-бейдж, дисциплина, «осталось N дн.» с плюрализацией —
красным при ≤3 днях — и кнопкой действия в раздел сессии (/schedule).

#### Scenario: срочный дедлайн

- **WHEN** до зачёта осталось 2 дня
- **THEN** подпись «осталось 2 дня» помечена `data-urgent` и окрашена
  цветом ошибки.

#### Scenario: дедлайнов нет

- **WHEN** будущих сессий нет
- **THEN** показан EmptyState «Дедлайнов нет».

### Requirement: «Как у меня дела»

Блок ДОЛЖЕН показывать кольцо среднего балла (взвешенный процент от
максимума), бейдж риска по долгам («1 долг — пересдача <дата>» или
«Долгов нет») и мини-полоски по дисциплинам с цветом по уровню
(≥85 — success, 70–84 — warning, ниже — error).

#### Scenario: один долг

- **WHEN** у студента одна будущая пересдача 18 ноября
- **THEN** бейдж: «1 долг — пересдача 18 ноября».

### Requirement: Быстрые действия и новости деканата

На главной ДОЛЖНЫ быть блок «Быстрые действия» (Заказать справку,
Подать заявление → /requests; Написать в деканат → /deanery; Спросить AI →
/ai-assistant) и блок «Новости деканата» с горизонтальными карточками
вымышленного фида, ведущими в раздел уведомлений до появления ленты новостей
(DIG-36).

#### Scenario: быстрое действие

- **WHEN** пользователь нажимает «Спросить AI»
- **THEN** открывается /ai-assistant.

### Requirement: Загрузка и отзывчивость

Главная ДОЛЖНА показывать скелетон на время загрузки (стриминг Suspense с
фолбэком, повторяющим геометрию блоков), работать на 360 px (одна колонка,
hero-плитки 2×2) и на 1440 px без горизонтального скролла.

#### Scenario: мобильный 360

- **WHEN** студент открывает главную на 360×800
- **THEN** блоки идут одной колонкой, плитки героя — сеткой 2×2,
  горизонтального скролла нет.
