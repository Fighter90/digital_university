# Proposal: главная «Ваша неделя» — hero, сегодня, дедлайны, «как у меня дела» (DIG-20)

## Зачем

Главная кабинета (`/dashboard`) до DIG-20 — каркасный плейсхолдер («Кабинет
студента»). По макету Figma «02 Главная + M2» она должна собирать всё важное за
пару касаний: тёмный hero со сводкой недели, таймлайн сегодняшних пар,
ближайшие дедлайны, панель самочувствия учёбы, быстрые действия и новости
деканата. Отдельное требование приёмки — один серверный запрос-агрегат
(без водопада запросов, как в аудированном ЛК с 21 запросом).

## Что

- `src/server/data/dashboard.ts` → `getDashboard(db, ctx, now)`: агрегат из
  **пяти параллельных** чтений изолированного порта данных (profile, schedule,
  exams, grades, requests) через `Promise.all`. Сбой одного источника оседает
  в `Section<T> { ok: true | false }` — страница отрисовывает собственное
  состояние ошибки блока, остальные блоки живы.
- Строка-резюме героя выводится **детерминированно из данных**
  (`buildWeekSummary` в `src/lib/dashboard-format.ts`, без LLM):
  «Сегодня 4 пары, одна перенесена, одна отменена. До пересдачи 7 дней.»
- Hero «Ваша неделя · <день, дата>» — единственный тёмный блок (neutral-900,
  коралловое свечение — blur-слои поверх блока): приветствие по имени и времени суток,
  сводка, 4 плитки-ссылки (средний балл с дельтой → /grades, кредиты X/240 →
  /profile, долги → /schedule, заявки в работе → /requests); 2×2 на 360 px.
- «Сегодня»: таймлайн пар группы (время, пилюля типа по токенам занятий,
  дисциплина, ауд., преподаватель). `ROOM_CHANGED` — пунктир + жёлтый фон +
  «Перенос: ауд. 214 → 305» (из `previousRoom`); `CANCELLED` — зачёркнута;
  аудитория «Онлайн» — ссылка «Онлайн». Пустой день — EmptyState «Нет пар
  сегодня» + ближайший учебный день.
- «Ближайшие дедлайны»: будущие сессии группы (зачёт/экзамен/пересдача),
  дата-бейдж, «осталось N дн.» с плюрализацией, красным при ≤3 днях
  (`data-urgent`), кнопка «Подробнее» → /schedule.
- «Как у меня дела»: кольцо среднего балла (взвешенный % от максимума),
  бейдж риска по долгам («1 долг — пересдача 18 ноября» / «Долгов нет»),
  мини-полоски по дисциплинам: ≥85 — success, 70–84 — warning, ниже — error.
- «Быстрые действия»: Заказать справку, Подать заявление → /requests;
  Написать в деканат → /deanery; Спросить AI → /ai-assistant.
- «Новости деканата»: вымышленный статичный фид из 5 карточек
  (`src/server/data/news.ts`, горизонтальный snap-scroll); реальную ленту
  подключит DIG-36, карточки ведут в фид уведомлений (события NEWS).
- Загрузка: страница — `<Suspense fallback={<DashboardSkeleton/>}>`, контент —
  асинхронный блок с одним агрегатом (стриминг скелетона).
- Демо-набор (`demo-seed.ts`) обогащён «сегодняшним» днём ПИ-21 (4 пары:
  перенесённая 214→305, отменённая, онлайн), срочным зачётом через 2 дня
  (красное «осталось 2 дня») и пересдачей через 7 дней — чтобы прототип
  совпадал с референсом задачи («Сегодня 4 пары, одна перенесена…
  До пересдачи N дней»).

## Кредиты и долги (детерминированные допущения)

- Кредиты: ≈60 ECTS за учебный год, источник — курс студента
  (`creditsForCourse`: course × 60, ограничение 240). Отдельного справочника
  в схеме нет — допущение зафиксировано тестом.
- Долги: будущие `RETAKE`-сессии группы из порта данных (никаких новых полей).

## Отклонения от текста задачи (обоснованные)

- Резюме-строка задачи («Сегодня 4 пары…») — пример макета; на экране она
  собирается из фактических данных (число пар/переносов/отмен/пересдач).
- «Ссылка "Онлайн"» ведёт на /schedule: модели онлайн-встречи в схеме нет
  (формат пары — аудитория «Онлайн»); детали пары — DIG-24.
- Скелетон реализован стримингом RSC (Suspense), а не клиентским стором —
  данные всё равно приходят одним серверным запросом-агрегатом.

## Вне скоупа

- Реальная лента новостей (DIG-36), детали пары (DIG-24), неделя расписания
  (DIG-22), сотруднический вариант главной (DIG-48).
