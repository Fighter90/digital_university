# DIG-72 — Плавающая кнопка AI-ассистента (FAB) с попап-чатом: OpenRouter + RAG по справке

## Why

Полноэкранный AI-ассистент DIG-46 (карточки действий) требует перехода на
отдельный экран — до него надо дойти. Для конкурса нужен вход «всегда под
рукой»: плавающая кнопка в правом нижнем углу кабинета, по клику — всплывающее
окно чата, где можно сразу задать вопрос. Ответы — через OpenRouter
(chat-completions, ключ только в серверном env), заземлённые на справку
кабинета (RAG по «Справке» /guide, DIG-70, и «Вопросам и ответам» /help,
DIG-38) — без внешних embedding API, лексическим скорингом.

## What Changes

- **FAB-кнопка**: плавающая круглая кнопка (coral-500 токены, иконка
  Sparkles) в правом нижнем углу ВСЕХ страниц кабинета — теперь и на десктопе
  (раньше была только на мобильном). На мобильном поднята над таб-баром,
  на десктопе отступ от края не мешает контенту. Скрывается на самом экране
  `/ai-assistant` (не дублировать вход) и у сотрудника. Открывает попап-чат
  DIG-72; полноэкранная панель DIG-46 остаётся доступной по кнопке AI в шапке.
- **Попап-чат**: на десктопе — карточка 400 px у кнопки с хвостиком, на
  мобильном 360 px — bottom-sheet на весь экран с ручкой. Заголовок
  «AI-ассистент», кнопка закрытия, история текущей сессии в памяти компонента
  (не в БД), поле ввода + кнопка отправки, Enter отправляет.
- **OpenRouter (серверно)**: чистый клиент fetch к
  `https://openrouter.ai/api/v1/chat/completions`; ключ ТОЛЬКО из
  `process.env.OPENROUTER_API_KEY` (никогда на клиент/в репо), модель —
  бесплатная llama-класса (переопределяется `OPENROUTER_MODEL`), таймаут 20 c,
  повторов нет. Новых SDK-зависимостей нет.
- **RAG по справке**: индекс чанков = секции GUIDE_SECTIONS (/guide) +
  вопросы/ответы FAQ_ARTICLES (/help). Retrieval — лексический скоринг
  (стемминг из DIG-38, частота слов запроса по чанку, буст заголовка,
  русский + английский ключи), топ-3 чанка в промпт. Системный промпт:
  отвечай только по справке кабинета; если данных нет — честно скажи и
  предложи открыть справку или создать обращение. Ответ рендерится как текст
  (markdown-сырец снимается на сервере).
- **Fallback (обязателен)**: нет ключа / API недоступен / ошибка → демо-режим:
  релевантный чанк справки как «подсказка из справки» с пометкой о демо-режиме.
  Жюри без ключа видит работающий прототип без падений.
- **Безопасность**: rate-limit 10 вопросов/мин на сессию (скользящее окно,
  как DIG-11/DIG-47/DIG-64), обрезка входа ≤ 1000 символов, в лог — только
  факт вызова и длина (не сам вопрос), action за requireDataCtx.
- **Экран /ai-assistant не ломается**: карточки DIG-46 на месте; попап —
  отдельный лёгкий вход.

## Impact

- Спека: новая capability `floating-assistant` (delta — ADDED requirements).
- Чистый модуль: `src/lib/floating-assistant-knowledge.ts` (чанки, retrieval,
  промпт, снятие markdown).
- Сервер: `src/server/ai/openrouter.ts` (fetch-клиент), 
  `src/server/ai/floating-assistant.ts` (лимитер + оркестратор ответа),
  `src/server/actions/floating-assistant.ts` (server action).
- UI: `src/components/assistant/floating-assistant-popup.tsx` (client),
  `src/components/shell/ai-fab.tsx` (десктоп-видимость), 
  `src/components/shell/shell.tsx` (FAB → попап, скрытие на /ai-assistant),
  `src/components/shell/ai-guide.tsx` (десктоп-пилюля/панель гида сдвинуты
  левее FAB — без взаимного перекрытия).
- Env: `.env.example` — имена `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`.
- Тесты: `tests/floating-assistant-knowledge.test.ts`,
  `tests/floating-assistant-service.test.ts`,
  `tests/floating-assistant-popup.test.tsx`,
  `e2e/floating-assistant.spec.ts`; обновлены точки входа в
  `e2e/assistant.spec.ts` (панель DIG-46 — кнопка шапки) и актуализирован
  локатор FAB в `e2e/ai-guide.spec.ts`.
- e2e и unit НЕ ходят в реальный OpenRouter: e2e стартует сервер без ключа
  (детерминированный fallback), unit — с инъекцией fetch.

## Non-goals

- Сохранение истории чата в БД — история только в памяти вкладки.
- Стриминг ответа от модели (панель DIG-46 стримит локальный движок; попапу
  достаточно разового ответа), retry и ротация моделей.
- Изменения экрана /ai-assistant и движка карточек DIG-46.
- Векторные/embedding-индексы и внешние API поиска.
