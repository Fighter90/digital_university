# DIG-13 — Дизайн-система: токены, шрифт, базовые компоненты

## Зачем

Все экраны кабинета (DIG-14…DIG-48) должны собираться из одних компонентов и
одних токенов. Сейчас в коде — каркас DIG-6 со случайными neutral-цветами и
шрифтом Inter. Эталон визуального языка — макеты «Цифровой деканат»
(светлая версия ResumeCraft).

## Что делаем

1. **Токены** в `src/app/globals.css`: CSS-переменные `:root` + Tailwind v4
   `@theme inline` (утилиты `bg-accent`, `text-success-ink`, `rounded-card`,
   `shadow-soft`, …). Палитра: фон `#F7F7F7`, карточки `#FFFFFF`, границы
   `#EBEBEB`, текст `#222222`, вторичный `#6A6A6A`, приглушённый `#9A9A9A`;
   акцент `#FF385C`, градиент `#E61E4D → #E31C5F → #D70466`, мягкий акцент
   `#FFF1F3`; статусы успех/предупреждение/ошибка/инфо; типы занятий
   (лекция/семинар/лаб/экзамен + «перенос» — штриховка и пунктир); радиусы
   8/12–16/24/999; тени soft/hover.
2. **Шрифт Onest** (OFL) через `next/font/google`, веса 400–800, latin+cyrillic,
   заголовки 800 с трекингом −0.02…−0.03em. Inter из каркаса убираем.
3. **Компоненты** `src/components/ui`: Button, Chip, Card, StatTile, Badge,
   Stepper, ProgressRing, Toggle, Segmented, Sheet, Dialog, Toast, Skeleton,
   EmptyState, ErrorState, Tooltip, Avatar + обёртка Icon (lucide, stroke 1.8).
4. **Галерея `/design`** — только в dev (`notFound()` в проде), показывает все
   компоненты и состояния.
5. **Доступность**: глобальное видимое кольцо фокуса `:focus-visible`
   (2px, контраст ≥ 3:1), клавиатурная навигация (Stepper/Segmented/Toggle).

## Разрешение конфликта «токен ↔ AA»

Пары «текст на мягком фоне» из макета не для всех статусов дают 4.5:1
(#008A05 на #E9F6EA = 4.06:1). Поэтому у каждого статуса три токена:
`--du-<status>` (иконки/заливки), `--du-<status>-soft` (фон), `--du-<status>-ink`
(текст на мягком фоне, AA 4.5:1+). `#9A9A9A` — только декор/дизейбл (не текст):
AA-пары в тесте его не используют.

## Non-goals

- Тёмная тема (светлая версия по макету).
- Shell (DIG-14), экраны кабинета, замена neutral-классов на старых
  страницах-заглушках login/dashboard (их перепишут свои задачи).
- Пиксельная привязка к Figma через API (в задании даны точные значения токенов).
