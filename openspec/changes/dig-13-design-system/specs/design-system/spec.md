# Спека: design-system (delta)

## ADDED Requirements

### Requirement: Дизайн-токены

Палитра, радиусы, тени и типографика приложения определены токенами в
`src/app/globals.css` (CSS-переменные + Tailwind v4 `@theme inline`) и
едины для всех экранов.

#### Scenario: Токены соответствуют макету

- **WHEN** парсится `globals.css`
- **THEN** определены: фон `#F7F7F7`, карточки `#FFFFFF`, границы `#EBEBEB`,
  текст `#222222`, вторичный текст `#6A6A6A`, приглушённый `#9A9A9A`,
  акцент `#FF385C`, градиент `#E61E4D → #E31C5F → #D70466`, мягкий акцент
  `#FFF1F3`, статусы успех `#008A05`/`#E9F6EA`, предупреждение `#9A6400`/
  `#FBF3E2`, ошибка `#C13515`/`#FDECEA`, инфо `#1D4ED8`/`#EAF1FE`
- **AND** радиусы: кнопки 8px, карточки 12–16px, крупные блоки 24px, пилюли 999px
- **AND** тени: soft `0 1px 2px rgba(0,0,0,.06)`, hover
  `0 16px 38px rgba(0,0,0,.10)`

### Requirement: Контраст AA

Все пары «цвет текста ↔ фон», объявленные в словаре токенов, имеют контраст
не ниже 4.5:1 (WCAG AA). Для каждого статуса есть отдельный ink-токен для
текста на мягком фоне; `#9A9A9A` используется только для декора/дизейбла.

#### Scenario: Пары текста проходят AA

- **WHEN** считается контраст каждой текстовой пары из словаря
  (текст/фон/карточка, ink на мягких фонах, белый на градиенте и статусах)
- **THEN** каждая пара ≥ 4.5:1

### Requirement: Шрифт Onest

Интерфейсный шрифт — Onest (OFL), подключён через `next/font/google`,
веса 400–800, подмножества latin+cyrillic; заголовки — вес 800 и
letter-spacing −0.02…−0.03em.

#### Scenario: Шрифт подключён

- **WHEN** читается `src/app/layout.tsx`
- **THEN** используется `Onest` из `next/font/google` с весами 400–800

### Requirement: Базовые компоненты

В `src/components/ui` есть: Button (primary-градиент, secondary, ghost,
danger; высоты 40/48), Chip-фильтр, Card, StatTile, Badge (единый словарь
статусов), Stepper (5 шагов, done/current/pending/rejected/ready),
ProgressRing, Toggle, Segmented (День/Неделя/Месяц), Sheet (справа,
снизу на мобильном), Dialog, Toast, Skeleton, EmptyState, ErrorState,
Tooltip, Avatar (инициалы). Иконки — lucide-react, stroke 1.8.

#### Scenario: Компоненты собраны в ui-набор

- **WHEN** перечисляются файлы `src/components/ui`
- **THEN** все перечисленные компоненты существуют и экспортируются
  из barrel-модуля

### Requirement: Доступность

Все интерактивные компоненты доступны с клавиатуры и имеют видимое кольцо
фокуса `:focus-visible` с контрастом не ниже 3:1 к окружению.

#### Scenario: Фокус виден с клавиатуры

- **WHEN** пользователь нажимает Tab на странице `/design`
- **THEN** сфокусированный элемент имеет видимое кольцо фокуса

### Requirement: Галерея /design

Страница `/design` существует только в dev-режиме (в проде — 404) и
показывает все компоненты и их состояния.

#### Scenario: Галерея скрыта в проде

- **WHEN** сборка выполняется с NODE_ENV=production
- **THEN** страница `/design` отвечает 404

#### Scenario: Галерея видна в dev

- **WHEN** dev-сервер открыт на `/design` (1440 и 360)
- **THEN** все компоненты и состояния отрисованы
