# Proposal: публичный лендинг на «/» (DIG-57)

## Зачем

Корень «/» — заглушка из каркаса (DIG-6): заголовок и две ссылки. Жюри конкурса
первым делом попадает именно сюда: лендинг должен презентовать продукт — что
такое цифровой деканат, какие возможности даёт студенту, и куда идти дальше
(вход / демо-доступ).

## Что

- **Hero** «Всё университетское — в одном окне»: строка бренда «Цифровой
  деканат», подзаголовок с перечислением возможностей, две CTA — «Войти» и
  «Демо-доступ», декоративные «парящие» карточки-миниатюры (пара, оценка,
  готовая справка) на мягких световых пятнах.
- **Секции преимуществ (5 карточек)**: расписание, оценки, заявки, справки
  с QR, AI-ассистент — иконка + короткое описание. Hover — подъём и тень
  (`lift-hover`, токены DIG-13).
- **Финальный CTA-блок** и футер — повторный призыв и ссылка на вход.
- **Анимации**: плавное появление секций при прокрутке через
  `IntersectionObserver` (клиентский компонент `Reveal`, без тяжёлых
  зависимостей), каскадные задержки; hover-эффекты карточек. При
  `prefers-reduced-motion` анимации отключаются.
- **Дизайн-токены DIG-13**: Inter (уже в root layout), палитра акцента,
  радиусы (`rounded-card`, `rounded-block`, `rounded-pill`), тени
  (`shadow-soft`/`shadow-hover`), градиент бренда.
- **Мобайл 360 px**: одна колонка, без горизонтального скролла; декор
  hero упрощается.
- **Публичность**: лендинг открывается без авторизации; все CTA ведут на
  `/login` (демо-аккаунты подсказываются на экране входа чипами DIG-18).

## Non-goals

- Редирект авторизованных с «/» (лендинг публичный для всех; вход в кабинет
  остаётся через `/login` → `/dashboard`).
- Реальные фото/скриншоты кабинета и внешние библиотеки анимаций
  (framer-motion и т.п.) — только CSS + IntersectionObserver.
- Копирайтинг реального вуза: все тексты и цифры вымышленные, плашка
  «Концепт для конкурса» наследуется из корневого layout.

## Правила и допущения

- H1 hero содержит и имя продукта («Цифровой деканат»), и слоган задачи —
  контракт e2e smoke (DIG-6: h1 содержит «Цифровой деканат») сохраняется.
- «Reveal» — прогрессивное улучшение: без IntersectionObserver (старые
  окружения, jsdom) контент сразу видим; анимация только при
  `prefers-reduced-motion: no-preference`.
