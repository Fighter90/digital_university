# DIG-44 — Экран «Настройки»: главная, уведомления, безопасность, вид

## Why

Экран `/settings` (DIG-19) — плоский список из трёх карточек: каналы уведомлений,
тема, активные сессии. Нет управления виджетами главной, нет тихих часов, нет
смены пароля и завершения отдельных сеансов, тема не применяется к интерфейсу.
По Figma «02 · Профиль — настройки» (DIG-44) экран перестраивается в 4 вкладки.

## What Changes

- **Вкладки** `/settings`: Главная → Уведомления → Безопасность → Вид (ссылки,
  `?tab=`, server rendering, дефолт — «Главная»).
- **Вкладка «Главная»**: управление виджетами главной (Сегодня, Дедлайны,
  Успеваемость, Заявки, Новости, Мероприятия): включить/выключить, порядок —
  перетаскиванием И с клавиатуры (кнопки «вверх/вниз»), предпросмотр. Порядок и
  видимость сохраняются на сервере и применяются к `/dashboard` сразу.
- **Вкладка «Уведомления»**: матрица «категория × канал» (в кабинете, email,
  Telegram — заглушка «скоро») + тихие часы (окно времени, подавляет генерацию
  уведомлений в кабинете).
- **Вкладка «Безопасность»**: смена пароля (текущий → новый, argon2id), активные
  сеансы (устройство, браузер, город — недоступно в прототипе, время) с кнопкой
  «Завершить» для чужих сеансов и «Выйти на всех устройствах».
- **Вкладка «Вид»**: тема (светлая / тёмная / системная — тёмная теперь
  доступна и применяется к интерфейсу), язык (RU / EN — EN заглушка «скоро»),
  размер шрифта, «Уменьшить анимацию». Применение — server-side на `<html>`
  (классы `dark` / `font-lg` / `font-xl` / `reduce-motion`).

## Impact

- Спеки: `settings` (новая capability-спека), dashboard (виджеты → порядок).
- Модель настроек (`StudentSettingsRow`) расширяется: `widgets`, `quietHours`,
  `language`, `fontSize`, `reduceMotion`. Старые строки нормализуются
  (`normalizeSettings`) — миграция данных не нужна (прототип на memory-adapter).
- AuthStore расширяется: `setPasswordHash`, `deleteSessionById` (оба адаптера:
  memory + prisma). Владение сеансом проверяется по `userId` — IDOR исключён.
- Тёмная тема: переопределение токенов в globals.css (`.dark`), инверсия
  нейтральной шкалы Tailwind; светлые значения не меняются.

## Non-goals

- Перевод интерфейса на EN (заглушка «скоро»).
- Город сеанса по IP (в прототипе недоступно, показывается «—»).
- Раздел «Мероприятия» на главной — виджет-заглушка (контент придёт с DIG-43).
- Серверный push/email/telegram-каналы доставки (прототип: только лента).
