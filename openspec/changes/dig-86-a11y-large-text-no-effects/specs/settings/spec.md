# settings — delta (DIG-86)

## ADDED Requirements

### Requirement: Вкладка «Доступность» с режимом «Крупный текст и без эффектов»

Среди вкладок экрана `/settings` есть вкладка «Доступность»
(`?tab=accessibility`). На ней — карточка «Крупный текст и без эффектов»
с двумя независимыми клавиатурными переключателями (role="switch"):
«Крупный текст» и «Без эффектов». Подписи локализованы (RU/EN).
Состояние хранится в cookie `du-a11y` владельца сессии (значения:
`large-text`, `no-effects`, `large-text,no-effects`) и изменяется
только server action'ом `setA11y`, скоупленным сессией (анонимный
посетитель выпадает на /login; IDOR невозможен).

#### Scenario: Тумблеры отражают cookie

* WHEN студент с cookie `du-a11y = large-text,no-effects` открывает
  `/settings?tab=accessibility`
* THEN оба тумблера включены (aria-checked="true")
* WHEN cookie нет или она битая
* THEN оба тумблера выключены

#### Scenario: Переключение тумблера

* WHEN студент (или сотрудник — владелец сессии) переключает один тумблер
* THEN server action `setA11y` записывает cookie с каноническим значением
  (второй режим не затрагивается), кабинет перевалидируется, и классы на
  `<html>` обновляются при следующей отрисовке
* WHEN действие вызывается с неизвестным значением режима
* THEN запись отклоняется (false), cookie не меняется

### Requirement: Классы a11y-режима на <html>

Root layout читает cookie `du-a11y` и добавляет на `<html>` классы
`a11y-large-text` и/или `a11y-no-effects` server-side, до первой
отрисовки, на всех страницах (включая /login и кабинет сотрудника;
без cookie — классов нет). Классы дополняют appearanceClasses (DIG-44).

#### Scenario: Cookie → классы до первой отрисовки

* WHEN root layout рендерится с cookie `du-a11y = large-text,no-effects`
* THEN `<html>` содержит оба класса a11y-large-text и a11y-no-effects
* WHEN cookie нет
* THEN a11y-классов на `<html>` нет

### Requirement: CSS режима доступности в globals.css

`html.a11y-large-text` увеличивает базовый размер шрифта минимум до
112,5% (реализовано 125%, rem-масштаб всего кабинета), усиливает веса
обычного текста и увеличивает межстрочные/списочные отступы; правило
приоритетнее `html.font-lg`/`html.font-xl` (специфичность с двумя
классами). `html.a11y-no-effects` отключает анимации (animation: none
на всех элементах — контент никогда не скрыт), задаёт
transition-duration: 0, отключает тени (box-shadow: none; контур
:focus-visible остаётся) и делает reveal-секции видимыми сразу.
Правила живут вне media-запросов — режим независим от системного
prefers-reduced-motion; «Уменьшить анимацию» (html.reduce-motion,
DIG-44) продолжает работать само по себе. Токены дизайн-системы
(DIG-13) не переопределяются.

#### Scenario: Крупный текст масштабирует кабинет

* WHEN html получил класс a11y-large-text
* THEN базовый размер шрифта корня не меньше 112,5% (125%), и правило
  перекрывает «Вид → размер шрифта» при любых комбинациях

#### Scenario: Без эффектов — плоский статичный интерфейс

* WHEN html получил класс a11y-no-effects
* THEN анимации и плавные появления отключены, переходы мгновенны,
  тени отсутствуют, reveal-контент видим сразу
* AND системный prefers-reduced-motion и html.reduce-motion не затронуты
