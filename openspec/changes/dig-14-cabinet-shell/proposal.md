# Proposal: каркас кабинета — Shell (DIG-14)

## Зачем

Все экраны кабинета (DIG-20…DIG-48) садятся на общий лэйаут: верхняя панель,
боковое меню, мобильная навигация. Без Shell каждая экранная задача будет
изобретать свою навигацию, а критерии конкурса (мобильность 360 px,
доступность, единый дизайн) не проверить.

## Что

- `src/app/(cabinet)/layout.tsx` — серверная проверка сессии через `requireUser()`
  (до DIG-18 — детерминированный стаб с вымышленным студентом).
- Верхняя панель 72 px: вымышленный логотип, поиск-кнопка «Найти пару,
  преподавателя, справку…» (⌘K / Ctrl+K, заглушка палитры), AI, колокольчик
  с точкой непрочитанных, аватар с меню (Профиль, Настройки, Выйти),
  плашка «Концепт для конкурса».
- Боковое меню 212 px (≥1024): 8 разделов, активный — мягкий коралловый фон;
  карточка «Ближайший дедлайн» под меню. 768–1023 — иконочный рельс.
- Мобильный (<768, проверка на 360): нижний таб-бар (Главная, Расписание,
  Оценки, Заявки, Ещё) с safe-area iPhone, плавающая круглая AI-кнопка.
- Skip-link «К содержимому», `aria-current="page"` на активных пунктах
  (единая логика для меню и таб-бара в `nav-items.ts`).
- Счётчик уведомлений: SSR-значение + опрос `/api/notifications/count`
  каждые 60 с без перезагрузки.
- Каркасные маршруты-заглушки: schedule, grades, requests, notifications,
  deanery, ai-assistant, profile, settings, more.
- Коралловые токены в `globals.css` (рабочие, до финализации DIG-13).

## Раунд 2 — исправления ревью (2026-11-11)

- Страница `/dashboard` больше не рендерит собственный `<main>`: Shell
  владеет единственным main-landmark (`#main-content`), содержимое — в
  `<section>` (иначе невалидный вложенный landmark).
- `SearchPalette` возвращает фокус на кнопку поиска при закрытии
  (Escape / клик по фону / «Закрыть» / повторный ⌘K) — фокус не падает в
  `<body>`; убран бессмысленный `aria-hidden="false"` с видимого оверлея.
- Убраны тавтологические «инварианты исходников» (regex по файлам);
  вместо них поведенческие render-тесты страниц (unit, без браузера) и
  e2e-проверки: ровно один main-landmark, возврат фокуса, отсутствие
  aria-hidden на оверлее.

## Раунд 3 — исправления ревью (2026-11-11)

- В `tasks.md` уточнена запись о e2e: 15 тестов / 30 прогонов на два

  несовпадению вьюпорта; вместо неоднозначного «18 passed». Прогон

## Non-goals

- Реальная авторизация и signOut — DIG-18 (сейчас «Выйти» ведёт на /login).
- Реальные данные расписания/заявок/уведомлений — экраны DIG-21+; счётчик — DIG-35.
- Дизайн-система и финальные токены — DIG-13 (здесь только рабочий коралл).
- Поиск ⌘K как экран — DIG-45 (здесь заглушка-диалог).
