# DIG-66 — «Что изменилось»: AI-объяснение динамики оценок с интерактивным визуалом

## Why

Тренд Product Hunt: AI-анализ данных → интерактивные визуалы (OrangeLabs,
Scrumlens). Экран «Успеваемость» уже показывает цифры (GPA, кредиты,
рейтинг), но не объясняет их: студент видит «средний балл 30,3» без ответа
на главный вопрос — «что изменилось и почему?». Для конкурса нужен наглядный
AI-инсайт: человеческое объяснение динамики средней оценки за месяц +
интерактивный график, где каждая точка раскрывает, какие работы на неё
повлияли.

## What Changes

- **Карточка «Что изменилось»** на экране «Успеваемость» (`/grades`, после
  сводки с GPA-кольцом): детерминированное (без LLM и сети) объяснение
  динамики среднего балла за последние 30 дней — вырос / снизился / не
  изменился / появились первые работы, с именованной работой, повлиявшей
  сильнее всего.
- **Метрика совпадает с экраном**: средний балл в карточке считается по тем
  же формулам, что GPA-кольцо сводки (накопленная по плану контроля,
  нормировка на план, взвешивание кредитами) — числа карточки и сводки
  совпадают (требование e2e «данные совпадают с успеваемостью»).
- **Интерактивный график**: линия накопленного среднего по датам работ,
  точки-кнопки; наведение / фокус / нажатие на точку показывает список
  работ, сформировавших средний на эту дату (дисциплина, работа, балл).
- **Скоуп семестра**: тренд строится по семестру последней оценки (идущий
  семестр); карточка скрывается, если оценок нет вовсе.
- **Слой данных**: `getGradeInsight(db, ctx)` — выборка только по
  `ctx.studentId`/`ctx.groupName` из живой сессии (IDOR невозможен по
  построению); сотрудник — null + аудит ROLE_MISMATCH, как у остальных
  студенческих агрегатов.

## Impact

- Спека: новая capability `grade-insight` (delta — ADDED requirements).
- Чистый модуль: `src/lib/grade-insight.ts` (временные срезы среднего,
  дельты месяца, детерминированные тексты, DTO для клиентского компонента).
- Сервер: `src/server/data/grade-insight.ts` (`getGradeInsight`) + экспорт
  в `src/server/data/index.ts`.
- UI: `src/components/performance/grade-insight-card.tsx` (client,
  интерактив), подключение в `src/app/(cabinet)/grades/(summary)/page.tsx`.
- Тесты: `tests/grade-insight.test.ts` (unit: срезы, тексты, скоупинг,
  аудит), `e2e/grade-insight.spec.ts` (рендер карточки, совпадение с
  кольцом GPA, интерактив точек, 360 px без горизонтального скролла).

## Non-goals

- Никакого LLM/внешних сервисов: объяснения — детерминированные тексты по
  локальным данным (конкурсный прототип, вымышленные данные).
- Карточка не мутирует данные: серверных экшенов нет, только чтение.
- Отдельные экраны/страницы для тренда и исторические графики прошлых
  семестров — вне задачи.
