# Proposal: P2 — низкие дефекты BUG-12…BUG-20 — косметика и удобство (DIG-85)

## Зачем

QA-регресс 18.11, раздел 5.4 (таблица 2): девять устойчиво воспроизводимых
дефектов низкой важности, не влияющих на сценарии и безопасность. Выполняется
после конкурса (после 22.11) — ветка готовится заранее, merge решает
оркестратор. Пункты берутся по частям, каждый — фикc + проверка (DoD задачи).

## Что (по пунктам)

- **BUG-12 (проверить остаток)**: корень React #418 (гидрация, таймзона)
  закрыт DIG-79. Остаток фиксируется контррегрессионным тестом-сканером:
  в клиентских компонентах запрещено форматировать даты без явного
  `timeZone` (Intl.DateTimeFormat/toLocale*String) — источник мисматча
  SSR/клиент вернулся бы незаметно.
- **BUG-13 (2 из 9 предзагружаемых чанков → 404)**: на текущей сборке
  не воспроизводится (`app-build-manifest.json` ↔ `.next/static` консистентны;
  подозрение — раскатка/стейл HTML при замене сборки). В репозитории
  добавляется гард-тест: после `next build` каждый чанк, на который ссылается
  манифест сборки и пререндер-HTML, обязан существовать на диске.
- **BUG-14 (карточка переноса дублирует неизменное время)**: пары с
  `ROOM_CHANGED`, у которых `previousStartsAt` совпадает со временем пары,
  показывали «было: ауд. 214 / 12:00» — время в «было» не менялось.
  Видовой слой (`schedule-view.ts`, `schedule-cards.ts`) показывает часть
  «было: <время>» только при реальном изменении московского настенного
  времени; часть «было: ауд.» — только при реальной смене аудитории.
- **BUG-15 (единый стиль аудиторий)**: «ауд. А-312» и «каб. А-401»/
  «каб. 214» в одном продукте. Единый канон — «ауд. {room}»: ключ
  `session.room.short`, локации ICS-календаря (`calendar.ts`), тексты
  уведомлений (`session.ts`, `demo-seed.ts`), часы приёма справочника
  сотрудников (`people-catalog.ts`), статические тексты новостей/справки.
  EN остаётся «room N» (уже единый). Правило перевода уведомлений
  (`ru-translit.ts`) принимает оба варианта (в БД живут старые тексты).
- **BUG-16 (PDF без текстового слоя)**: все PDF (справка, выписка,
  справка об обучении) рисованы глифами-прямоугольниками — скринридер
  молчит, код проверки не скопировать. Писатель `pdf-writer.ts` получает
  невидимый текстовый слой: та же геометрия строк, шрифт Helvetica
  (WinAnsi, без вложений), режим отрисовки `3 Tr`, `/Lang (ru-RU)`;
  кириллица транслитерируется (таблица в писателе), ASCII (код проверки,
  URL, номера, даты) — байт-в-байт.
- **BUG-17 (кнопка «Синхронизировать» без отклика)**: рядом с кнопкой
  появляется живой статус (role="status", aria-live): «Обновляем…» пока
  идёт refresh, «Расписание обновлено» после (гаснет через ~2.5 с).
- **BUG-18 («Прослушать день» молчит без движков)**: браузеры без
  голосовых движков (headless, некоторые Android WebView) не дают ни
  `onstart`, ни ошибки. Кнопка ставит сторож-таймер: если озвучка не
  стартовала (~1.2 с) — честное запасное сообщение role="status"
  «Голосовой движок недоступен…», состояние сбрасывается; синхронная
  ошибка тоже показывает сообщение (раньше — тихий idle).
- **BUG-19 (после неудачного входа остаётся signedOut=1)**:LoginForm при
  ошибке входа убирает `signedOut` из адреса (history.replaceState) и
  прячет устаревшее «Вы вышли из кабинета» — не показываем два
  противоречащих сообщения одновременно.
- **BUG-20 (кнопка «Отправить» неактивна до чекбокса без объяснения)**:
  на шаге «Проверка» рядом с неактивной кнопкой появляется пояснение
  «Кнопка станет активной после отметки согласия выше» (исчезает после
  отметки).

## Non-goals

- Статусы/жизненный цикл Linear — владеет оркестратор.
- Миграции/схема Prisma, слой данных переносов (правится только вывод),
  seed `previousStartsAt` оставлен как есть — фикс видовой, работает и
  со старыми данными в БД.
- Инфраструктура деплоя (Caddy/compose) не меняется: 404 чанков при
  подмене сборки лечится гард-тестом сборки, не инфраструктурой.
- Вложение шрифта в PDF запрещено правилами репозитория — текстовый слой
  строится на стандартном Helvetica без файлов шрифтов.

## Риски

- Транслитерация в PDF-слое — компромисс (кириллица стандартным шрифтом
  без вложений невозможна); код проверки, URL, даты — ASCII без потерь.
- Гард-тесты BUG-12/13 сканируют исходники/артефакты — держатся на
  эвристиках с чёрными списками, чтобы не ловить ложные срабатывания.
