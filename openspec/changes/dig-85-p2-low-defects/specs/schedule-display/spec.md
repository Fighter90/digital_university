# Delta-spec: schedule-display — низкие дефекты P2 (BUG-12…BUG-20)

## MODIFIED Requirements

### Requirement: Метка переноса пары («было …»)

Карточка/блок переноса показывает часть «было: …» только о том, что реально
изменилось. Время входит в «было» только при изменении московского настенного
времени начала; аудитория — только при изменении строки аудитории.

- **WHEN** пара имеет статус ROOM_CHANGED и `previousStartsAt` совпадает по
  настенному времени (Europe/Moscow) с текущим началом
  **THEN** `previousTimeLabel` и временная часть `previousLabel` равны null —
  показывается только «было: ауд. …» (дубль «было: 15:00» при новом 15:00
  запрещён).
- **WHEN** пара имеет статус TIME_CHANGED (время реально изменилось)
  **THEN** «было: <время>» печатается как прежде.
- **WHEN** `previousRoom` равен текущей аудитории
  **THEN** «было: ауд. …» не печатается (работает и для старых данных в БД).

### Requirement: Стиль аудиторий в интерфейсе и документах

Аудитории, куда идёт студент (пары, экзамены, консультации, деканат),
печатаются в едином стиле «ауд. {номер}» (EN — «room {номер}»). Стили
«каб. …» и «голый номер» в студентском интерфейсе запрещены.

- **WHEN** студент открывает сессию (экзамены, консультации, пересдачи)
  **THEN** аудитория печатается как «ауд. А-401» (ключ `session.room.short`).
- **WHEN** студент подписывается на ICS-календарь (сессия и расписание)
  **THEN** LOCATION событий — «ауд. {номер}».
- **WHEN** студент читает уведомления о пересдаче/переносе и новости/справку
  о часах приёма
  **THEN** аудитории в текстах — «ауд. …»; правило перевода EN понимает и
  старые записи «каб. …» (данные в БД не мигрируются).

### Requirement: Текстовый слой PDF-документов

PDF справки, выписки и справки об обучении несут невидимый текстовый слой:
каждая видимая строка дублируется текстом стандартного шрифта Helvetica
(WinAnsi, без вложенных файлов) в режиме отрисовки 3 Tr, документ помечен
/Lang (ru-RU).

- **WHEN** получатель открывает PDF скринридером
  **THEN** читается текст документа (кириллица — транслитерацией латиницей).
- **WHEN** получатель копирует текст из PDF
  **THEN** код проверки, ссылка проверки, номер документа и даты копируются
  посимвольно точно (ASCII — без транслитерации).
- **WHEN** PDF собирается при равных входах
  **THEN** вывод остаётся байт-в-байт детерминированным.

### Requirement: Отклик кнопки «Синхронизировать»

Кнопка «Синхронизировать» недельного вида даёт видимый статус обновления.

- **WHEN** студент нажимает «Синхронизировать»
  **THEN** рядом появляется статус (role="status", aria-live="polite")
  «Обновляем…», а после завершения refresh — «Расписание обновлено»
  (гаснет автоматически); нажатие без статуса запрещено.

### Requirement: Запасное поведение «Прослушать день»

- **WHEN** браузер содержит speechSynthesis, но голосовые движки недоступны
  (озвучка не стартовала) **THEN** в течение ~1.2 с появляется запасное
  сообщение role="status" «Голосовой движок недоступен…», кнопка
  возвращается в исходное состояние; молчаливое «ничего не произошло»
  запрещено.
- **WHEN** SpeechSynthesisUtterance бросает исключение
  **THEN** показывается то же запасное сообщение.

### Requirement: Вход после выхода

- **WHEN** вход с /login?signedOut=1 завершается ошибкой
  **THEN** параметр signedOut убирается из адресной строки (без перезагрузки
  страницы) и устаревший статус «Вы вышли из кабинета» скрывается — вместе с
  ошибкой не показывается ни одного противоречащего сообщения.

### Requirement: Пояснение у неактивной «Отправить»

- **WHEN** мастер заявки на шаге «Проверка» и согласие не отмечено
  **THEN** рядом с неактивной кнопкой «Отправить» виден поясняющий текст,
  что кнопка станет активной после отметки согласия; после отметки
  пояснение исчезает.

## ADDED Requirements

### Requirement: Гард гидрации (таймзона в клиентских компонентах)

- **WHEN** клиентский компонент форматирует дату во время рендера
  **THEN** форматирование задаёт явный timeZone (Europe/Moscow); вызовы
  Intl.DateTimeFormat без timeZone и toLocale*String в 'use client'-файлах
  запрещены и ловятся юнит-сканером (корень React #418 не возвращается).

### Requirement: Гард консистентности сборки (чанки)

- **WHEN** выполнен `next build` **THEN** каждый файл, на который ссылается
  app-build-manifest.json и пререндер-HTML (`/_next/static/…`), существует
  в `.next` — сборка не может отдать предзагрузку несуществующего чанкам
  (источник 404 BUG-13).
