# Delta spec: seeding (DIG-10)

## ADDED Requirements

### Requirement: Идемпотентный сид демо-данных

Сид `pnpm db:seed` наполняет БД вымышленными данными; повторный запуск не
создаёт дубликатов (финальное состояние одинаково после любого числа запусков).

#### Scenario: Повторный запуск сида

- WHEN выполняют `pnpm db:seed` второй раз без изменения кода
- THEN счётчики всех таблиц совпадают с первым запуском, дублей нет.

### Requirement: Живое расписание относительно текущей недели

Расписание генерируется на семестр (≈8 недель назад … ≈6 недель вперёд от
текущего понедельника). На текущей неделе ровно: 1 перенос аудитории,
1 перенос времени, 1 отмена. Сессия (зачёты, экзамены, 1 пересдача) — в
последние 2 недели семестра.

#### Scenario: Демо живое в любой день

- WHEN сид выполняют в произвольную дату (до 28.11 и после)
- THEN в диапазоне семестра содержится текущая дата, исключения приходятся
  на текущую неделю, сессия лежит внутри семестра.

### Requirement: Только вымышленные данные и безопасные пароли

Все email — на домене `example.edu`; ФИО преподавателей — из собственного
вымышленного списка; в сидах пароли только как bcrypt-хэши, открытые пароли —
только в README для жюри.

#### Scenario: Проверка ПДн и паролей

- WHEN читают prisma/*.ts и README
- THEN в сидах нет открытых паролей, все хэши соответствуют формату bcrypt,
  email только `@example.edu`, README содержит тестовые аккаунты.
