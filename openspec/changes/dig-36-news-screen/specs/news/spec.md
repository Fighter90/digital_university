# Delta: news (DIG-36) — новости и объявления

## ADDED Requirements

### Requirement: Лента с личным скоупом по умолчанию

Лента `/news` ДОЛЖНА (MUST) показывать новости по вкладкам скоупа: «Моя группа»
(по умолчанию), «Мой факультет», «Весь вуз». Вкладка фильтрует каталог:
группа — только новости группы студента, факультет — только факультета,
вуз — общий поток. По умолчанию студент видит личный скоуп (группу),
а не общий поток вуза. Сотруднику деканата (без группы) вкладка «Моя
группа» заменяется на «Мой факультет». Вкладки — ссылки с сохранением
темы фильтра (работают без JS); радиогруппа со стрелками ←/→.

#### Scenario: дефолт — группа студента

- **WHEN** Анна (ПИ-21, ИТ) открывает `/news` без параметров
- **THEN** активна вкладка «Моя группа», в ленте только новости ПИ-21,
  новости ЭК-11 и факультета ЭК отсутствуют; обложки в ленте —
  `<img>` с alt и `loading="lazy"`.

#### Scenario: вкладки скоупа

- **WHEN** студент переключает вкладку «Весь вуз»
- **THEN** в ленте появляются общие новости вуза (в т.ч. чужого
  факультета по явному выбору), тема фильтра сохраняется.

#### Scenario: сотрудник без группы

- **WHEN** сотрудник деканата (факультет ИТ) открывает `/news`
- **THEN** эффективная вкладка — «Мой факультет» (отмечена), лента —
  новости факультета ИТ и вуза по выбору.

### Requirement: Полоса объявлений деканата

Требование «Полоса объявлений деканата» — обязательное (MUST): Важные объявления ДОЛЖНЫ идти отдельной полосой сверху ленты
(«Важно: изменился порядок пересдач») в скоупе текущей вкладки. У
непрочитанного объявления — маркер «новое», у прочитанного — пометка
«Прочитано». Открытие новости помечает её прочитанной в слое данных
(owner-scoped по студенту, идемпотентно); чужие отметки недостижимы.

#### Scenario: «Прочитано» после открытия

- **WHEN** студент открывает объявление и возвращается в ленту
- **THEN** у объявления в полосе стоит пометка «Прочитано»; отметка
  видна только владельцу (отметка Ильи не видна Анне).

### Requirement: Фильтр по темам

Лента ДОЛЖНА (MUST) фильтроваться темами пилюлями: Все, Учёба, Мероприятия,
Стипендии, Общежитие. Тема фильтрует вместе со скоупом (AND), выбор
сохраняется в URL (`?topic=…`) и переживает перезагрузку. На 360 px
пилюли скроллятся горизонтально.

#### Scenario: фильтр темы со скоупом

- **WHEN** Анна на вкладке «Весь вуз» нажимает пилюлю «Общежитие»
- **THEN** в ленте только новости темы «Общежитие»; на вкладке
  «Моя группа» при пустом результате — состояние «Новостей пока нет».

### Requirement: Карточка новости

Карточка ДОЛЖНА (MUST) показывать обложку-иллюстрацию (статичный SVG с
человеческим alt, `loading="lazy"`, `decoding="async"`), дату, источник,
заголовок и 2 строки текста (line-clamp-2); карточка целиком ведёт на
`/news/<id>`. Блок «Новости деканата» на главной ведёт карточками на
те же страницы новостей.

#### Scenario: карточка в ленте

- **WHEN** лента отрисовывается
- **THEN** каждая карточка содержит дату («12 ноября 2026»), источник
  («Деканат»), заголовок без точки в конце и усечённый текст.

### Requirement: Страница новости

Страница `/news/<id>` ДОЛЖНА (MUST) показывать заголовок, дату, источник,
автора, текст абзацами и вложения (статичные вымышленные файлы,
скачиваемые по ссылке), кнопку «Поделиться ссылкой» (clipboard с
фолбэком, состояние «Ссылка скопирована» — aria-live) и возврат в
ленту. Неизвестный id — HTTP 404.

#### Scenario: статья с вложением и шерингом

- **WHEN** студент открывает «Изменился порядок пересдач»
- **THEN** видны дата, источник «Деканат», автор «Мария Петрова»,
  абзацы текста, вложение «Порядок пересдач (извлечение)»; кнопка
  «Поделиться ссылкой» показывает «Ссылка скопирована».

#### Scenario: неизвестная новость

- **WHEN** открывают `/news/no-such-id`
- **THEN** сервер отвечает 404 (not-found UI), а не пустой экран.

### Requirement: Отметки «Прочитано» — данные владельца

Требование «Отметки «Прочитано» — данные владельца» — обязательное (MUST): Отметки «Прочитано» ДОЛЖНЫ храниться в слое данных owner-scoped по
`studentId` (порт `listNewsReadIdsByStudent` / `markNewsReadByStudent`);
id новости валидируется белым списком каталога ДО записи; сотруднику
отметки не пишутся (нет студенческого скоупа) — лента работает.

#### Scenario: изоляция отметок

- **WHEN** Илья отмечает новость прочитанной
- **THEN** в отметках Анны этой новости нет; повторное открытие не
  дублирует отметку; неизвестный id отклоняется без записи.
