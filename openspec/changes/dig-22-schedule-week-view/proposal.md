# Proposal: «Расписание: неделя» — недельный вид в стиле Google Calendar (DIG-22)

## Зачем

Экран `/schedule` до DIG-22 — каркасный плейсхолдер. Это главный вид
расписания кабинета (Figma «03 · Расписание — неделя», референс — светлый
календарь ResumeCraft): неделя целиком на сетке 08:00–20:00, перенос и
отмена видны с первого взгляда, листание недель — без перезагрузки страницы.
Серверная часть уже готова (DIG-21): `getSchedule`, московское время,
`pageMoscowWeek` с границами семестра — экран опирается на неё, слой данных
не меняется.

## Что

- `src/lib/schedule-view.ts` — чистая вью-логика экрана (без серверных
  импортов): ключ ISO-недели «2026-W46» для URL (`?week=`) с валидацией
  мусора и 53-недельных годов, подпись недели «9 – 15 ноября 2026»,
  позиционирование блоков (`top = (start − 480)/60·64`,
  `height = duration/60·64`), раскладка пересечений (пары делят ширину
  колонки, «встык» — не пересечение), серийализуемые модели блоков с
  понятным `aria-label`, цвета типов занятий на дизайн-токенах DIG-13,
  мини-календарь месяца целыми строками Пн–Вс, `resolveWeekPage` —
  парсинг + кламп по границам семестра + соседние недели.
- `src/app/(cabinet)/schedule/page.tsx` — серверная страница:
  `requireDataCtx` (скоуп из живой сессии, IDOR невозможен), `getSchedule`
  за интервал недели, сборка моделей; STAFF — явная заглушка
  («Расписание доступно студентам», сбой фиксирует аудит ROLE_MISMATCH
  на слое данных при его вызове), ошибка загрузки — ErrorState,
  пустая неделя — EmptyState «На этой неделе пар нет».
- `src/components/schedule/week-view.tsx` — клиентский WeekView:
  тулбар («Сегодня», стрелки ‹ › с отключением на границах семестра,
  подпись недели, День / Неделя / Месяц — день и месяц отключены как
  несуществующие виды, кнопка «Синхронизировать» → `router.refresh()`),
  левая колонка (мини-календарь: отображаемая неделя тонирована, сегодня —
  коралловый круг; фильтры типов занятия с цветными чекбоксами
  и счётчиками; фильтр по преподавателю), сетка 08:00–20:00 по 64 px
  на час с колонкой сегодняшнего дня в `coral-50` и красной линией
  текущего времени (обновление раз в минуту, client-only — без SSR
  мисматча), блоки пар-кнопки по цветам типов (лекция — коралловый,
  семинар — синий, лабораторная — зелёный, консультация — янтарный),
  перенос — серая штриховка + пунктирная рамка + бейдж «Перенос» +
  «было: ауд. 214 / 11:10», отмена — зачёркнутый заголовок, бледный блок,
  бейдж «Отменена». Клик по паре — боковая панель деталей (Sheet);
  полная карточка пары — задача DIG-24.
- Клавиатура: ←/→ листают недели (`router.push` → URL `?week=2026-W46`
  меняется без перезагрузки страницы), Esc закрывает панель; ввод в полях
  и радиогруппа переключателя вида не перехватываются.
- Мобильная замена: `< 768 px` недельный вид скрыт (`hidden md:block`),
  показывается заглушка «Мобильная версия расписания» — мобильный день
  делается отдельно (DIG-23).
- `src/app/(cabinet)/schedule/loading.tsx` — скелетон экрана на время
  загрузки RSC-данных.
- `src/components/ui/segmented.tsx` (DIG-13, аддитивно): опция `disabled`
  — пропускается при навигации стрелками, помечается `aria-disabled`.

## Ограничения

- Данные только из изолированного порта DIG-12/DIG-21; схема БД не меняется.
- Вид «День» (десктоп) и «Месяц» — вне скоупа: опции отключены; мобильный
  день — DIG-23, карточка пары — DIG-24.
- Никаких новых env-переменных; секреты не затрагиваются.

## Отклонения от текста задачи (зафиксированы по ревью раунда 2)

- **Фрейм Figma**: в задаче назван «04 · Расписание — неделя»; каноничное
  соответствие «экран ↔ задача» (`docs/figma-screens.md`) — «03 Расписание:
  неделя» → DIG-22, «04» — «Детали пары» (DIG-24). Ссылки в коде и спеке —
  на «03».
- **«Экзамен — янтарный»**: вида занятия EXAM в данных DIG-21 нет
  (`ScheduleKind = LECTURE | PRACTICE | LAB | SEMINAR | CONSULTATION`),
  янтарные токены `lesson-exam` закреплены за «Консультацией»; при
  появлении EXAM токены переходят ему (см. спеку).
- **Неделя целиком вне семестра** (`?week=2027-W30`): рендерится неделя
  «сейчас» (фолбэк без редиректа), а не кламп к границе семестра; кламп
  работает для страницы «сейчас» и валидных граничных недель; «сейчас»
  вне семестра — заглушка «Сейчас вне семестра». Уточнено в спеке.
