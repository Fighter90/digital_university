# Delta: performance — экран «Успеваемость: сводка» (DIG-26)

## ADDED Requirements

### Requirement: Сводка «как у меня дела»

Экран `/grades` ДОЛЖЕН показывать кольцо среднего балла выбранного
семестра (итог ?? накопленная, вес — кредиты), дельту к предыдущему
семестру со знаком и короткой подписью предыдущего семестра (не с чем
сравнивать → дельта не показывается), GPA за всё время, прогресс кредитов
«набрано из 240» (полоса + aria-валу) и место в группе «N из M» с
формулировкой «Вы входите в X% лучших в группе» и тултипом «Как считается».

#### Scenario: идущий семестр с дельтой

- **WHEN** осень 2026/27: GPA семестра 27,14, весной 2025/26 GPA 81,22
- **THEN** кольцо «27,1», дельта «−54,1 к Весна 25/26», кредиты «9 из 240»,
  рейтинг «2 из 5» с «Вы входите в 40% лучших в группе».

#### Scenario: завершённый семестр

- **WHEN** выбрана весна 2025/26 (итоги 87 и 74)
- **THEN** кольцо «81,2», дельты нет (предыдущий семестр пуст), на
  карточках «Экзамен сдан», словесные уровни «Отлично» / «Хорошо».

### Requirement: Выбор семестра

Экран ДОЛЖЕН показывать пилюли семестров: семестры с оценками плюс
текущий (даже пустой), по убыванию, с короткими подписями («Осень 26/27»).
Активная пилюля помечена aria-current. Параметр `?semester=YYYY-FALL|
YYYY-SPRING` выбирает семестр; мусор откатывается к дефолту. Дефолт —
текущий семестр, а если в нём нет оценок — ближайший семестр с оценками.
Безоценочные дисциплины остаются в срезе текущего семестра.

#### Scenario: дефолт при пустом текущем семестре

- **WHEN** в текущем семестре оценок ещё нет, последняя оценка — весна
- **THEN** открыт семестр с последними оценками, кольцо показывает его GPA.

#### Scenario: пустой выбранный семестр

- **WHEN** в выбранном семестре нет ни одной оценки
- **THEN** вместо карточек — «Оценок пока нет» с подсказкой о первой
  контрольной («Первая контрольная — зачёт по … 14 ноября»); светофор
  нейтрален (idle).

### Requirement: Карточки дисциплин

Карточка дисциплины ДОЛЖНА показывать название, преподавателя (из
справочника группы), кредиты («4 кр.»), крупную оценку («87» итог /
«48,9» накопленная / «—» без оценок), «из возможных 88,9» для идущей,
словесный уровень рядом с цветом («Отлично», «Хорошо», «Порог уже
набран», «Порог ещё не гарантирован», «Не дотянуть до порога», «Ниже
порога», «Оценок ещё нет») и бейдж допуска к экзамену: «Экзамен сдан» /
«Допуск к экзамену есть» (неоценён только экзамен) / «Допуска к экзамену
нет» (есть и другие несданные) / без бейджа (в плане нет экзамена). Клик
ведёт в зачётную книжку `/grades/gradebook?discipline=CODE`.

#### Scenario: допуска нет

- **WHEN** сдан 1 из 3 элементов, среди несданных — не только экзамен
- **THEN** бейдж «Допуска к экзамену нет» (warning).

#### Scenario: дисциплина без экзамена в плане

- **WHEN** план дисциплины без экзаменационного элемента
- **THEN** бейджа допуска нет ни в каком виде.

### Requirement: Светофор состояния

Экран ДОЛЖЕН показывать светофор с приоритетом: активные долги («Есть
долги», «Активных долгов: N. Ближайшая пересдача — …», действие к
#debts) > риски («Есть риски», N дисциплин с недостижимым порогом,
действие к сессии) > всё хорошо («Всё хорошо», действие к сессии) >
«Оценок пока нет» (без действия). Тон светофора имеет и статус бейджа
(debts=error, risk=warning, ok=success, idle=neutral).

#### Scenario: долги важнее рисков

- **WHEN** есть и просроченный долг, и дисциплина в зоне риска
- **THEN** тон debts, фраза с ближайшей пересдачей, действие ведёт к блоку долгов.

### Requirement: Долги

Блок «Долги» (#debts) ДОЛЖЕН перечислять незакрытые пересдачи со статусом
(«Назначена» info / «Просрочена» error), фразой даты («Пересдача назначена
на 19 ноября (осталось 7 дней)» / «Пересдача была 8 ноября — долг не
закрыт») и ссылкой «Записаться на пересдачу» → /deanery.

#### Scenario: активные долги

- **WHEN** есть просроченная и назначенная пересдачи
- **THEN** обе строки с фразами дат; закрытые долги в блоке не показываются.

### Requirement: Доступ и состояние экрана

Данные ДОЛЖНЫ читаться только на сервере из `getPerformance(dataDb, ctx)`
и `listExams(dataDb, ctx)` с ctx из живой сессии; `?semester=` влияет
только на срез уже своих данных. Сотруднику (studentId = null) — заглушка
«Экран доступен студентам» без обращения к данным. Ошибка агрегата —
ErrorState «Успеваемость не загрузилась» с «Повторить» (role=alert).
Пока агрегат грузится — скелетон (loading.tsx → GradesSkeleton, aria-busy).
Страница живёт в main-регионе Shell и не заводит собственный <main>.

#### Scenario: сотрудник

- **WHEN** ctx.role = STAFF
- **THEN** заглушка «Экран доступен студентам», студенческих данных нет.

#### Scenario: ошибка данных

- **WHEN** getPerformance отклоняется
- **THEN** role=alert, «Успеваемость не загрузилась», кнопка «Повторить».
