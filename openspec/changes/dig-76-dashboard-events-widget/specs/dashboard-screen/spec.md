# DIG-76 — delta: Виджет «Мероприятия» на главной

## ADDED Requirements

### Requirement: Виджет «Мероприятия» — реальные ближайшие события

Виджет «Мероприятия» на главной ОБЯЗАН (MUST) показывать до трёх
ближайших БУДУЩИХ событий вуза из слоя данных (фасад events.ts,
`getDashboardEvents` от now), а не статическую заглушку: дата и время
старта, название, место или «Онлайн», «Осталось N мест» («Мест нет»
при нуле) и чип «Записан» на событиях, на которые владелец сессии
записан (`registeredByMe` — скоуп `ctx.studentId`, никогда ввод).
Виджет ОБЯЗАН (MUST) содержать ссылку «Все мероприятия» → /events,
а каждая мини-карточка — ссылку на карточку события /events/<slug>.
Запись на событие из виджета не выполняется — существующий
owner-scoped `toggleEventRegistrationAction` остаётся единственной
мутацией (на карточке события). Чтение афиши — любой вошедший.

#### Scenario: Виджет показывает ближайшие события

- **WHEN** вошедший студент открывает /dashboard, и в данных есть
  будущие события (сид: 8 событий, ближайшие через 2–5 дней)
- **THEN** виджет показывает мини-карточки ближайших событий с датой,
  названием, местом («Онлайн» для трансляций), «Осталось N мест» и
  чипом «Записан» на записанных владельцем; заглушка «скоро появятся»
  не показывается; ссылка «Все мероприятия» ведёт на /events

#### Scenario: Чип «Записан» — скоуп владельца

- **WHEN** два студента с разными записями открывают /dashboard
- **THEN** каждый видит «Записан» только на своих событиях (флаг из
  контекста сессии, не из ввода); у сотрудника чипов нет

### Requirement: Честное пустое состояние и изоляция сбоя

Если будущих событий нет, виджет ОБЯЗАН (MUST) показывать прежнее
пустое состояние «Мероприятия скоро появятся» (честный empty-state,
без ссылки «Все мероприятия»). Сбой источника событий ОБЯЗАН (MUST)
оседать в состояние ошибки самого блока («Блок «Мероприятия» не
загрузился», role="alert") и не ронять главную: остальные блоки
продолжают работать. Пока агрегат грузится, скелетон ОБЯЗАН (MUST)
содержать блок «Мероприятия».

#### Scenario: Нет будущих событий

- **WHEN** все события в данных прошли (или событий нет)
- **THEN** виджет показывает «Мероприятия скоро появятся» и не рендерит
  список и ссылку «Все мероприятия»

#### Scenario: Сбой источника

- **WHEN** чтение ближайших событий падает (например, хранилище
  недоступно)
- **THEN** блок «Мероприятия» показывает собственную ошибку, страница
  и остальные виджеты работают

### Requirement: Локализация виджета RU/EN

Строки виджета ОБЯЗАНЫ (MUST) идти из словаря по локали (cookie
du-locale, дефолт ru): заголовок блока, «Все мероприятия», «Записан»,
«Онлайн», «Осталось N мест»; даты — Intl по локали; в EN-рендере
демо-события титул и место — из en-demo-content (кириллицы нет).

#### Scenario: EN-рендер

- **WHEN** студент переключил интерфейс на EN и открывает /dashboard
- **THEN** виджет показывает «All events», «Registered», «N spots left»
  и EN-названия демо-событий без кириллицы
