# help-knowledge-base — delta

## MODIFIED Requirement: Оглавление справки не ломается на длинных заголовках

**Поведение:** пункт оглавления с длинным заголовком обрезается многоточием
на границе своей колонки (16rem); текст никогда не вылезает на соседнюю
колонку контента и не распирает раскладку. Требование действует в обычной и
в plain-версии, на 1440px и 1024px.

#### Scenario: длинный заголовок не вылезает за колонку (обычная версия)

- **WHEN** страница `/guide` открыта на 1440px в обычной версии
- **THEN** правый край `<a>` любого пункта оглавления не превышает правый
  край его карточки-оглавления (overflow 0px)
- **AND** ширина `<a>` не превышает ширину колонки оглавления

#### Scenario: длинный заголовок не вылезает за колонку (plain-версия)

- **WHEN** страница `/guide` открыта на 1440px в plain-версии
  (cookie `du-a11y-version=plain`)
- **THEN** ни один элемент страницы не шире viewport (нет горизонтального
  скролла)
- **AND** контентные секции не перекрывают оглавление при прокрутке
  (sticky отключён: оглавление прокручивается вместе с контентом)
- **AND** шапка не шире viewport (переносится на 2 строки)
