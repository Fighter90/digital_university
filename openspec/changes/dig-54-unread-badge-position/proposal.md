# Proposal: фикс позиции счётчика непрочитанных (DIG-54)

## Зачем

Баг на проде (ostrovok.store): красный бейдж непрочитанных «3» висит в отрыве
от элемента — над пунктом «Главная» сайдбара / краем шапки. Причина:
`UnreadBadge` рендерится с `absolute -top-0.5 -right-0.5`, а в `SideNav` его
обёртка и все предки до `<aside class="sticky">` — static. `position: sticky`
делает aside positioned-предком, поэтому бейдж позиционировался относительно
угла сайдбара.

## Что

- Колокольчик top-bar — канонический контейнер бейджа: `data-testid=
  "unread-badge"`, бейдж `absolute` внутри него (relative-контейнер), виден
  на 1440 и 360 (колокольчик в шапке виден на обоих вьюпортах; таб-бар
  уведомлений не содержит — точка входа на мобильном та же шапка, кадр Figma
  «Shell · Кабинет» DIG-14).
- `UnreadBadge` получил вариант `variant="inline"` (по умолчанию `floating`):
  в строке сайдбара «Уведомления» бейдж — элемент потока без `absolute`,
  физически не может покинуть строку при любом positioned-предке.
- При 0 непрочитанных бейдж не рендерится нигде (уже было, покрыто тестами).
- e2e: геометрическая проверка — бейдж целиком внутри контейнера колокольчика
  (допуск 3 px на уголок), не пересекается с сайдбаром ни по одной оси;
  на 360 — внутри колокольчика; счётчик скрывается при нуле (polling-тест).

## Non-goals

- Бейдж в мобильном таб-баре: в таб-баре нет вкладки уведомлений (DIG-14:
  Главная / Расписание / Оценки / Заявки / Ещё) — не изобретаем.
- Дизайн/размеры бейджа не меняются (цвет coral-500, 16 px — токены DIG-13).
- Pre-existing падение `tests/grades-page.test.tsx` (пустое состояние семестра,
  сид/дата) — вне задачи, воспроизводится на чистом HEAD; выделено в
  отдельную Linear-задачу DIG-67 (раунд 2, замечание ревью), чтобы не жило
  вечно после `openspec archive`.
