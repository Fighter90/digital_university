# DIG-104 — Регресс RU: гидрация расписания (два server/client дефекта)

## Зачем

Регресс-прогон кабинета студента против прода (https://ostrovok.store, RU,
anna.smirnova, desktop 1440 + mobile 360) зафиксировал на `/schedule` и
`/schedule?view=day` (обе ширины) необработанную ошибку React #418:
«Hydration failed because the server rendered HTML didn't match the client».
На этих маршрутах сходились ДВА дефекта гидрации — оба воспроизведены и
исправлены локально (dev-сервер с неминифицированным React):

### Дефект 1: вложенные `<a>` в карточке пары

Карточка пары (`EventCard`, DIG-24) целиком является `<a>`, а подпись
преподавателя внутри неё (DIG-37) — вложенный `<Link>` (тоже `<a>`).
Вложенные якоря — невалидный HTML: парсер браузера переставляет дерево
(внешний `<a>` закрывается при встрече внутреннего), SSR-разметка расходится
с ожидаемой, React выбрасывает #418 и перерисовывает всё дерево на клиенте.

### Дефект 2: server/client ветка в «Прослушать день»

`ListenDayButton` (DIG-65) проверял `isSpeechSynthesisSupported()` прямо в
рендере: SSR (без `window`) рисовал `null`, браузер (со `speechSynthesis`) —
кнопку `<button data-testid="listen-day">` перед списком пар. Первый рендер
клиента не совпал с серверной разметкой → тот же #418.

## Что делаем

- `EventCard` (href-ветка) → паттерн «stretched link»: пустой `<a>` деталей
  растянут на карточку (`absolute inset-0`), контент лежит поверх
  (`pointer-events-none`), ссылка преподавателя — `pointer-events-auto`
  и не вложена в якорь деталей.
- `ListenDayButton`: доступность движка озвучки (`window.speechSynthesis`)
  читается через `useSyncExternalStore` — серверный снапшот всегда `false`,
  первый рендер всегда без кнопки (SSR и клиент совпадают), кнопка
  появляется после гидрации, если движок есть.
- `data-testid="day-card-<id>"` переносится с якоря на `<li>`, чтобы ссылка
  преподавателя оставалась потомком карточки (контракты e2e/people.spec).
  `data-event-id` и `aria-label` остаются на якоре деталей (возврат фокуса
  по Esc в event-details-panel ищет `[data-event-id]`).
- Красно-первый тесты: `tests/schedule-card-nested-links.test.tsx` (вложенные
  `<a>`) и `tests/listen-day-hydration.test.tsx` (SSR-строка без кнопки).

## Non-goals

- `src/components/events/event-card.tsx` (лента мероприятий) не трогаем:
  регресс на `/events` не зафиксирован.
- Виды «неделя» и «месяц» не трогаем: вложенных якорей там нет
  (компактные строки без ссылки преподавателя).
- Инфраструктура роя `scripts/swarm/` не затрагивается.

## Альтернативы (отклонены)

- Убрать ссылку преподавателя из карточек дня — ломает DIG-37 и e2e
  «переход из карточки пары в справочник».
- Заменить якорь карточки на `div onClick` — теряет семантику ссылки и
  возможность «открыть в новой вкладке» (DIG-24).
- Показывать кнопку озвучки по `suppressHydrationWarning` — прячет симптом,
  не чинит рассинхрон.
