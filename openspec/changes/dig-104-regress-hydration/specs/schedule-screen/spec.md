# Delta — schedule-screen: карточка пары без вложенных якорей

## MODIFIED Requirements

### Requirement: Доступность блока пары

Карточка пары со ссылкой на детали (`?event=<id>`) не содержит вложенных
элементов `<a>`: HTML остаётся валидным, гидрация React проходит без
ошибки #418 на серверном и клиентском рендере.

Контракт кликабельности сохраняется:

- весь блок кликабелен и ведёт на панель деталей (stretched-ссылка
  `absolute inset-0` с `aria-label` пары и `data-event-id`);
- подпись преподавателя остаётся самостоятельной ссылкой на справочник
  (DIG-37), кликабельной поверх stretched-ссылки;
- возврат фокуса по закрытию панели (Esc) находит карточку по
  `[data-event-id]`;
- `data-testid="day-card-<id>"` размещён на элементе списка карточки
  (`<li>`), ссылка преподавателя остаётся его потомком.

#### Scenario: Вид «день» гидрируется без ошибок

- **WHEN** студент открывает `/schedule` (авто) или `/schedule?view=day`
- **THEN** консоль браузера не содержит `Hydration failed` / React #418

#### Scenario: Документ не содержит вложенных якорей

- **WHEN** рендерится вид «день» (десктопный список и мобильная лента)
- **THEN** во всём документе `document.querySelectorAll('a a').length === 0`

#### Scenario: Клик по преподавателю ведёт в справочник

- **WHEN** студент кликает подпись преподавателя в карточке пары
- **THEN** открывается `/people/<teacher>` (не панель деталей пары)

#### Scenario: Клик по карточке открывает детали

- **WHEN** студент кликает карточку пары
- **THEN** URL получает `?event=<id>` и открывается панель деталей;
  после Esc фокус возвращается на карточку

## ADDED Requirements

### Requirement: «Прослушать день» без server/client ветки в рендере

Кнопка озвучки дня (`ListenDayButton`, DIG-65) читает доступность браузерного
движка `speechSynthesis` через `useSyncExternalStore` (серверный снапшот —
всегда `false`). Первый рендер (SSR и гидрация) всегда рисует `null` —
разметка не зависит от наличия `window`; кнопка появляется после гидрации,
если движок есть.

#### Scenario: Вид «день» (мобильная лента) гидрируется без ошибок

- **WHEN** студент с включённой настройкой «Озвучка и голосовой ввод»
  открывает `/schedule` или `/schedule?view=day` в браузере с движком озвучки
- **THEN** консоль не содержит `Hydration failed` / React #418

#### Scenario: SSR-разметка не зависит от браузера

- **WHEN** рендерится мобильный вид дня (server HTML)
- **THEN** в разметке нет `data-testid="listen-day"`; после монтирования
  в браузере с движком кнопка появляется, без движка — не появляется
