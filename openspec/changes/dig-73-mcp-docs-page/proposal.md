# DIG-73 — Страница документации MCP (/mcp): «как подключить ассистента»

## Why

MCP-сервер деканата (DIG-64) работает: оценки/расписание/уведомления по
персональному токену доступны в ChatGPT/Claude. Но у фичи нет понятной
страницы-инструкции и заметного входа из меню — как у Linear
(linear.app/docs/mcp). Жюри и студент должны за один клик понять, что такое
MCP, что доступно и как подключить ассистента.

## What Changes

- **Страница `/mcp`** (GET-only, серверный компонент каркаса кабинета;
  доступна студенту и сотруднику):
  - «Что это»: MCP — открытый протокол, по которому любой AI-ассистент
    (Claude, ChatGPT, Cursor) securely читает ваши данные деканата.
  - «Что доступно»: раздел строится из каталога инструментов
    `DEANERY_MCP_TOOLS` (`/api/mcp`) — расписание на сегодня, оценки,
    непрочитанные уведомления (в т.ч. дедлайны). Документация не может
    обещать больше, чем отдаёт сервер.
  - «Как подключить» (шаги): персональный токен → JSON-конфиг → примеры
    вопросов. Конфиг-сниппет JSON для Claude Desktop/Cursor с кнопкой
    «Скопировать конфиг»; токен в сниппете — плейсхолдер `<ВАШ_ТОКЕН>`,
    рядом — маскированное превью выпущенного токена (plaintext в системе
    не хранится, показывается один раз при выпуске в настройках).
  - «Безопасность»: токен персонален и отзывается (перевыпускается) в
    настройках, доступ read-only, владелец видит только свои данные.
- **Пункт меню**: `MORE_SECTIONS += { href: '/mcp', label: 'Подключить
  ассистента (MCP)' }`, иконка Plug; `/mcp` подсвечивает вкладку «Ещё».
- **Справка**: раздел в `/guide` «Подключить внешнего AI-ассистента (MCP)»
  (шаги + callout про токен) + FAQ-статья в `/help` (категория IT, CTA на /mcp).
- **i18n**: RU/EN ключи `menu.mcp` и `title.mcp` в обоих словарях, маппинги
  в `sectionTitle`/`navLabel`. Контент страницы — вымышленный демо-контент
  (не переводится, как /guide и /help).

## Impact

- Новые файлы: `src/lib/mcp-docs.ts` (чистый контент/сниппет), 
  `src/components/mcp/mcp-connect-card.tsx` (client: токен + копирование),
  `src/app/(cabinet)/mcp/page.tsx`, `tests/mcp-docs-page.test.tsx`,
  `e2e/mcp-docs.spec.ts`.
- Изменения: nav-items, nav-icons, i18n (ru/en/index), help-content,
  faq-kb-catalog, tests/cabinet-shell.test.ts (пин списка «Ещё»).
- Серверных мутаций нет: страница GET-only, поверхностей записи нет;
  токен-вью — существующий owner-scoped `getOwnMcpTokenView` (только
  для STUDENT-ctx, IDOR невозможен).

## Non-goals

- Расширение MCP-сервера (новые инструменты: GPA/неделя/заявки) — вне задачи.
- Перевод контента страницы на EN (демо-контент, как у /guide и /help).
- Изменения вкладки «Настройка MCP» в /settings (обратная ссылка не требуется).
