# mcp-docs — delta (DIG-73)

## ADDED Requirements

### Requirement: Страница документации MCP (/mcp)

Требование «Страница документации MCP (/mcp)» — обязательное (MUST): Приложение предоставляет GET-only страницу `/mcp` в каркасе кабинета,
доступную аутентифицированным студентам и сотрудникам. Страница объясняет:
что такое MCP (Model Context Protocol), какие данные отдаёт MCP-сервер
деканата (каталог инструментов `/api/mcp`), как подключить внешний
AI-ассистент (пошагово), и правила безопасности токена. Страница не
выполняет мутаций (нет server actions и форм записи), показывает плашку
«Концепт для конкурса» каркаса и вымышленный демо-контент.

#### Scenario: Студент открывает страницу из меню «Ещё»

* WHEN студент открывает «Ещё» и выбирает «Подключить ассистента (MCP)»
* THEN открывается `/mcp` с секциями «что это», «что доступно», «как
  подключить», «безопасность» и вкладка «Ещё» подсвечена

#### Scenario: Сотрудник открывает страницу

* WHEN аутентифицированный сотрудник открывает `/mcp`
* THEN страница рендерится без персонального токена (токен выпускается
  владельцем студенческого кабинета) и без записей в аудит

### Requirement: Конфиг-сниппет без реальных ключей

Требование «Конфиг-сниппет без реальных ключей» — обязательное (MUST): Страница показывает готовый JSON-конфиг MCP-клиента (Claude Desktop /
Cursor) с кнопкой «Скопировать конфиг». Токен в сниппете — плейсхолдер
`<ВАШ_ТОКЕН>`; реальный ключ нигде не подставляется. Рядом страница
показывает маскированное превью выпущенного токена владельца (если токен
выпущен) и ссылку на `/settings?tab=mcp` для выпуска/перевыпуска.

#### Scenario: Сниппет безопасен

* WHEN страница рендерит конфиг-сниппет
* THEN в сниппете нет значения реального токена — только плейсхолдер
  `<ВАШ_ТОКЕН>`, а кнопка «Скопировать конфиг» копирует сниппет как есть

#### Scenario: Маскированный токен владельца

* WHEN студент с выпущенным токеном открывает `/mcp`
* THEN страница показывает превью вида `demo-mcp…XXXX` (не plaintext) и
  дату выпуска; полный токен остаётся доступным только один раз при выпуске

### Requirement: Вход из меню и справки

Требование «Вход из меню и справки» — обязательное (MUST): Пункт «Подключить ассистента (MCP)» присутствует в мобильном меню «Ещё»
(иконка Plug) и ведёт на `/mcp`; `/mcp` подсвечивает вкладку «Ещё».
Раздел «Подключить внешнего AI-ассистента (MCP)» присутствует в справке
`/guide`; FAQ-статья про подключение ассистента присутствует в `/help`.
Интерфейсные подписи пункта меню и заголовка локализованы RU/EN.

#### Scenario: Паритет локалей

* WHEN загружаются словари RU и EN
* THEN ключи `menu.mcp` и `title.mcp` существуют в обоих словарях и
  непусты
